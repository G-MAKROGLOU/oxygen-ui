# PricingPlans

A pricing-tier section: a responsive row of plan cards, each with a price, a
feature checklist, and a CTA.

## Quick start

```tsx
import { PricingPlans } from '@geomak/ui'

<PricingPlans title="Pricing" plans={[
  { name: 'Starter', price: '$0', period: '/mo', features: ['1 vessel', 'Email support'], cta: { label: 'Start free' } },
  { name: 'Pro', price: '$49', period: '/mo', highlighted: true, badge: 'Most popular',
    features: ['Unlimited vessels', 'Priority support'], cta: { label: 'Go Pro', onClick: goPro } },
]} />
```

Mark one plan `highlighted` to lift it (accent border, slight scale) and add a
`badge` ribbon. Collapses to one column on mobile, two on tablet.
