# SegmentedControl

A text-first segmented control for 2 to 4 mutually exclusive options (view
switchers, billing period, density). The selected segment lifts onto a
surface-white pill inside a tinted track, the macOS / iOS pattern, on Radix
toggle-group (arrow-key roving focus).

## Mental model

Driven by an `options` array; the value is a string. `onChange` reports the
value directly. Controlled (`value`) or uncontrolled (`defaultValue`). It's
a form field too: optional `label`/`helperText`/`errorMessage`, and a hidden
input when `name` is set.

> Use this for compact 2-4 choice switches. For navigating between content
> panes, use **Tabs** (`variant="segmented"`).

## Quick start

```tsx
import { SegmentedControl } from '@geomak/ui'

const [view, setView] = useState('list')

<SegmentedControl
  label="View"
  value={view}
  onChange={setView}
  options={[
    { value: 'list', label: 'List' },
    { value: 'board', label: 'Board' },
    { value: 'calendar', label: 'Calendar' },
  ]}
/>
```

## With the Form API

Bind with `field`:

```tsx
<SegmentedControl options={PERIODS} {...form.field('period', { required: true })} />
```

## Variants

```tsx
<SegmentedControl fullWidth options={OPTS} … />          {/* stretch, segments share width */}
<SegmentedControl size="sm" options={OPTS} … />          {/* sm | md | lg */}
<SegmentedControl options={[{ value:'list', label:'List', icon:<ListIcon/> }, …]} … />
<SegmentedControl label="Layout" layout="horizontal" required errorMessage="Pick one" … />
```
