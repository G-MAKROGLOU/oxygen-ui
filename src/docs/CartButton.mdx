# CartButton

A ready-made TopBar cart trigger: an icon button with a live item-count badge
overlaid on its corner. It reads the count straight from the cart store, so it
stays in sync no matter where items are added.

## Mental model

`CartButton` is a thin composition of `IconButton` + `Badge` wired to
`useCart()`. It must live inside a `CartProvider`. The badge shows
`getItemCount()` (total units) and auto-hides at zero; the count is also folded
into the accessible label (`"Cart (3)"`). You own what the click does: usually
open a cart `Drawer` or navigate to `Checkout`.

## Quick start

```tsx
import { CartProvider, CartButton, TopBar, AppShell } from '@geomak/ui'

<CartProvider>
  <AppShell
    topBar={
      <TopBar
        brand={<Logo />}
        actions={<CartButton onClick={() => setCartOpen(true)} />}
      />
    }
  >
    <ProductGrid />
  </AppShell>
</CartProvider>
```
