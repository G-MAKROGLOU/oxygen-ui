# CreditCardForm

A complete, validated card-entry form: number with brand detection + auto-format,
cardholder name, expiry (`MM/YY`), and CVV. Built on the library's Form API.

## Mental model

A self-contained form that manages its own fields and validation internally. You
receive a normalised `CreditCardValue` — `onChange` on every keystroke (possibly
invalid) and `onSubmit` once all fields pass. The card number is auto-formatted
and its brand detected live (`brand` is the detected id or `null`; digits are
returned without spaces). Embed it in a larger checkout by hiding the built-in
submit (`hideSubmit`) and driving submission from outside.

## Quick start

```tsx
import { CreditCardForm } from '@geomak/ui'

<CreditCardForm
  submitLabel="Pay $49"
  onSubmit={async (card) => {
    await charge({ number: card.number, expiry: card.expiry, cvv: card.cvv, brand: card.brand })
  }}
/>
```

## Embedded in a larger checkout

```tsx
<CreditCardForm
  hideSubmit
  requireName={false}
  onChange={setCard}
  defaultValue={{ name: user.fullName }}
/>
{/* your own submit elsewhere, using the latest `card` */}
```

## Gating the pay button

Use `submitDisabled` to block payment on an external condition while leaving the
fields editable (`disabled` would freeze everything). This is how the
**E-Commerce → Checkout** page disables Pay until the cart has items:

```tsx
<CreditCardForm submitDisabled={cartItems.length === 0} submitLabel={`Pay ${total}`} onSubmit={pay} />
```
