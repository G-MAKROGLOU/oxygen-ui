# OtpInput

A row of single-character boxes for one-time codes and PINs. Auto-advances on
type, supports paste of a full code, and Backspace moves back.

## Mental model

Controlled with a `string` of the concatenated characters. `onChange` reports the
next string; `onComplete` fires once every box is filled, which is the right hook
for auto-submit. `length` sets the box count, `mode` restricts the charset, and
`masked` hides characters for PIN entry.

## Quick start

```tsx
import { OtpInput } from '@geomak/ui'

const [code, setCode] = useState('')

<OtpInput
  label="Verification code"
  length={6}
  value={code}
  onChange={setCode}
  onComplete={(full) => verify(full)}
/>
```

## With the Form API

```tsx
<OtpInput label="Code" length={6} {...form.field('code', { required: true })} />
```

## PIN entry

```tsx
<OtpInput label="PIN" length={4} mode="numeric" masked value={pin} onChange={setPin} />
```
