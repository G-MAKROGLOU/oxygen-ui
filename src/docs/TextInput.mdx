# TextInput

A single-line text field. Full-width by default, with the shared field
foundation: label + error region + horizontal/vertical layout, the **Halo
Focus** (1px accent border + soft halo), and optional leading `prefix` /
trailing `suffix` adornments.

## Mental model

`TextInput` is controlled: you own the value via `value` + `onChange`. It wraps
the native `<input>` in the shared `<Field>` so the label, `helperText` tooltip,
required asterisk, and error message all render and align identically to every
other input. Constrain width with the parent or `style={{ maxWidth }}`.

## Quick start

```tsx
import { TextInput } from '@geomak/ui'

const [name, setName] = useState('')

<TextInput
  label="Vessel name"
  placeholder="e.g. Aurora"
  value={name}
  onChange={(e) => setName(e.target.value)}
/>
```

## With the Form API

Bind it with `fieldNative` (it reports `e.target.value`):

```tsx
<TextInput
  label="Email"
  {...form.fieldNative('email', { required: true, pattern: patterns.email })}
/>
```

See **Forms → Form API** for the full form layer.

## Adornments & type

```tsx
// Leading icon / trailing unit
<TextInput label="IMO" prefix={<HashIcon />} value={imo} onChange={onChange} />
<TextInput label="Speed" suffix="kn" value={speed} onChange={onChange} />

// Semantic types (keyboard + validation hints)
<TextInput type="email" label="Email" … />   // 'text' | 'email' | 'url' | 'tel'
```

## States

```tsx
<TextInput label="Name" errorMessage="Name is required" value="" onChange={…} />
<TextInput label="Name" disabled value="Locked" onChange={…} />
<TextInput label="Name" size="sm" … />            {/* sm | md | lg */}
<TextInput label="Name" layout="horizontal" … />  {/* label beside the field */}
<TextInput label="Name" helperText="Shown in a tooltip beside the label." … />
<TextInput label="Name" required … />             {/* asterisk + aria-required */}
```
