# AppShell

A full-page layout skeleton: sticky TopBar + collapsible Sidebar + scrollable
content area, wired together with responsive behaviour.

## Mental model

Compose the chrome by passing slots: a `topBar` node and `sidebarSections` data.
AppShell owns the sidebar's collapse state and the content offset, so you don't
shift content yourself. Responsive: at ≥768px the sidebar is inline and
collapsible; below that it becomes a fixed overlay drawer with an auto-injected
hamburger button beside the TopBar.

## Quick start

```tsx
import { AppShell, TopBar } from '@geomak/ui'

<AppShell
  topBar={<TopBar brand={<Logo />} actions={<ThemeSwitch checked={dark} onChange={onToggle} />} />}
  sidebarSections={NAV_SECTIONS}
  sidebarDefaultExpanded
  sidebarFooter={<UserMenu />}
>
  <PageContent />
</AppShell>
```
