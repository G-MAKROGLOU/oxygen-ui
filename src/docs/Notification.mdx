# Notification

Toast notifications: a provider holds the queue and portals the stack to a fixed
viewport corner; a hook fires type-specific toasts from anywhere.

## Mental model

Two pieces. Wrap your app once in `NotificationProvider` (it owns the stack,
animations, auto-dismiss, and viewport `position`). Then call `useNotification()`
inside any descendant to get four show functions — `info`, `success`, `warning`,
`danger` — each taking `{ title, description?, duration? }`. Toasts auto-dismiss
after `duration` ms (default 4000); pass `Infinity` to make one sticky.

## Setup

```tsx
import { NotificationProvider } from '@geomak/ui'

<NotificationProvider position="top-right">
  <App />
</NotificationProvider>
```

## Firing toasts

```tsx
import { useNotification } from '@geomak/ui'

function SaveButton() {
  const { success, danger } = useNotification()

  const onSave = async () => {
    try {
      await save()
      success({ title: 'Saved', description: 'Changes were stored.' })
    } catch {
      danger({ title: 'Save failed', description: 'Could not reach the server.', duration: Infinity })
    }
  }

  return <Button content="Save" onClick={onSave} />
}
```
