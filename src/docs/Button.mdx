# Button

The primary action control: four variants, three sizes, a leading icon slot, and
a built-in loading state.

## Mental model

Content goes in `content` (text or nodes). `variant` sets intent: `primary`
(filled accent), `secondary` (accent outline), `outline` (neutral hairline
outline), `ghost` (quiet), plus four status variants: `danger` (destructive),
`warning`, `success`, and `info`.
`loading` swaps in a spinner and disables the button. Width is never hardcoded:
let the parent flex/grid size it, or pass `style={{ width }}`.

## Quick start

```tsx
import { Button } from '@geomak/ui'

<Button content="Save" onClick={handleSave} />
<Button content="Delete" variant="danger" size="sm" />
<Button content="Cancel" variant="secondary" />
<Button content="Saving…" loading buttonType="submit" />
<Button content="New" variant="primary" icon={<PlusIcon />} />
```

## In a form

```tsx
<Button content="Submit" buttonType="submit" loading={form.isSubmitting} />
```
