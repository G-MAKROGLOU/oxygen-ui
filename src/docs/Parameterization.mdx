# Parameterization Guide

Three ways to customize the design system, in increasing order of depth.

---

## 1. CSS custom property override (recommended)

The simplest and most flexible method. Works at any CSS scope, no build dependency.

**Global override**: affects the entire app:

```css
/* After importing @geomak/ui/styles */
:root {
  --color-accent:       #7c3aed;
  --color-accent-hover: #6d28d9;
  --radius-md:          8px;
  --height-control-md:  40px;
  --height-topbar:      64px;
}

.dark {
  --color-accent:       #a78bfa;
  --color-accent-hover: #c4b5fd;
}
```

**Scoped override**: only inside a section:

```css
.admin-panel {
  --color-accent: #dc2626;
}

[data-theme="compact"] {
  --height-control-md: 30px;
  --height-control-lg: 36px;
  --height-topbar:     48px;
}
```

---

## 2. ThemeProvider component

React tree-scoped overrides. Generates CSS vars as inline styles on a wrapper element.

**Brand color swap:**

```tsx
import { ThemeProvider } from '@geomak/ui'

<ThemeProvider
  theme={{
    colors: {
      accent:              '#7c3aed',
      'accent-hover':      '#6d28d9',
      'accent-foreground': '#ffffff',
    }
  }}
>
  <App />
</ThemeProvider>
```

**Compact density:**

```tsx
<ThemeProvider
  theme={{
    density: {
      controlXs: 20,
      controlSm: 24,
      controlMd: 30,
      controlLg: 36,
      topbar:    48,
    }
  }}
>
  <DataTable />
</ThemeProvider>
```

**Custom font + type scale:**

```tsx
<ThemeProvider
  theme={{
    typography: {
      fontFamily:   '"Geist", sans-serif',
      fontSizeBase: '0.9375rem',
    }
  }}
>
  <App />
</ThemeProvider>
```

**Managed dark mode:**

```tsx
{/* Follow system preference */}
<ThemeProvider colorScheme="system"><App /></ThemeProvider>

{/* Force dark */}
<ThemeProvider colorScheme="dark"><App /></ThemeProvider>

{/* Different accent per mode */}
<ThemeProvider
  colorScheme="system"
  theme={{     colors: { accent: '#6366f1' } }}
  darkTheme={{ colors: { accent: '#818cf8' } }}
>
  <App />
</ThemeProvider>
```

### Full `ThemeConfig` type

```ts
interface ThemeConfig {
  colors?: {
    background?: string;  surface?: string;  'surface-raised'?: string
    border?: string;  'border-strong'?: string
    foreground?: string;  'foreground-secondary'?: string;  'foreground-muted'?: string
    accent?: string;  'accent-hover'?: string;  'accent-foreground'?: string
    error?: string;  warning?: string;  success?: string;  info?: string
  }
  radius?: {
    sm?: string | number;  md?: string | number;  lg?: string | number
    xl?: string | number;  '2xl'?: string | number;  full?: string | number
  }
  shadows?: { sm?: string;  md?: string;  lg?: string;  xl?: string }
  typography?: {
    fontFamily?: string      // e.g. '"Geist", sans-serif'
    fontSizeXs?: string;     fontSizeSm?: string;    fontSizeBase?: string
    fontSizeLg?: string;     fontSizeXl?: string;    fontSize2xl?: string;   fontSize3xl?: string
    fontWeightNormal?: number | string;   fontWeightMedium?: number | string
    fontWeightSemibold?: number | string; fontWeightBold?: number | string
  }
  density?: {
    controlXs?: string | number;  controlSm?: string | number
    controlMd?: string | number;  controlLg?: string | number
    topbar?: string | number
  }
  motion?: {
    durationFast?: string;  durationNormal?: string
    durationSlow?: string;  durationGentle?: string
  }
}
```

---

## 3. SCSS compile-time override (advanced)

Override `!default` variables before the token partial compiles: useful for eliminating the CSS var runtime layer entirely.

```scss
// your-app/src/styles/theme.scss
@use '@geomak/ui/src/styles/config' with (
  $color-accent:       #7c3aed,
  $color-accent-hover: #6d28d9,
  $color-dark-accent:  #a78bfa,
  $radius-md:          8px,
  $font-family-sans:   '"Geist"', sans-serif,
  $height-control-md:  40px,
);

@use '@geomak/ui/src/styles/tokens';
@use '@geomak/ui/src/styles/animations';

@tailwind base;
@tailwind components;
@tailwind utilities;
```

All `_config.scss` variables carry `!default`: only the variables you specify are overridden; the rest use system defaults.
