# IconButton

A square, icon-only button for toolbars and dense actions. Two variants, two
sizes, and a loading state.

## Mental model

Pass the glyph in `icon`. `type` picks the look (`primary` filled or `bordered`
outline). Always give a `title` for the accessible label / tooltip, since there's
no visible text. `loading` shows `loadingIcon` (or a default spinner) and disables
the control.

## Quick start

```tsx
import { IconButton } from '@geomak/ui'

<IconButton icon={<SearchIcon />} title="Search" onClick={doSearch} />
<IconButton type="bordered" icon={<EditIcon />} title="Edit" />
<IconButton icon={<SaveIcon />} title="Save" loading size="lg" />
```

## Pairing with Tooltip

```tsx
<Tooltip title="Delete record" placement="top">
  <IconButton icon={<TrashIcon />} title="Delete record" />
</Tooltip>
```
