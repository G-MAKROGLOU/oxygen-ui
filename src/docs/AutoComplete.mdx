# AutoComplete

A text input with a suggestions list. Works in two modes: **static** (filters a
provided `items` array as the user types) or **async** (resolves suggestions via
`onSearch`, debounced, with a loading state).

## Mental model

The input manages its own text internally; you react to a chosen suggestion via
`onItemClick(value)`. Items are `{ key, value, label, icon? }`. Provide `items`
for client-side filtering, **or** `onSearch` for a server lookup (the two are
mutually exclusive). It is not a controlled text field, so there's no
`value`/`onChange` pair.

## Static (client-side filter)

```tsx
import { AutoComplete } from '@geomak/ui'

<AutoComplete
  label="Vessel"
  placeholder="Search vessels…"
  items={vessels.map((v) => ({ key: v.imo, value: v.imo, label: v.name }))}
  onItemClick={(imo) => selectVessel(imo)}
/>
```

## Async (server lookup)

```tsx
<AutoComplete
  label="Port"
  debounce={300}
  onSearch={async (term) => {
    const res = await fetch(`/api/ports?q=${term}`)
    const data = await res.json()
    return data.map((p) => ({ key: p.unlocode, value: p.unlocode, label: p.name }))
  }}
  onItemClick={(code) => setPort(code)}
  loadingText="Searching…"
  emptyText="No matching ports"
/>
```

## With the Form API

Store the picked value yourself via `onItemClick`:

```tsx
<AutoComplete items={items} onItemClick={(v) => form.setValue('vessel', v)} errorMessage={form.errors.vessel} />
```
