# LoadingSpinner

Concentric rotating rings with an optional letter-by-letter caption. Works as a
fullscreen overlay or inline at the call site.

## Mental model

By default it renders a **fullscreen overlay** with a backdrop (blocks the UI
during a blocking load). Pass `inline` to drop the portal/overlay and render it in
place inside a card, table row, or empty-state slot. `prompt` reveals a caption
glyph-by-glyph; omit it for a pure spinner. Colors default to theme tokens but
accept any CSS color override.

## Quick start

```tsx
import { LoadingSpinner } from '@geomak/ui'

{/* fullscreen overlay while a route loads */}
{isLoading && <LoadingSpinner prompt="Loading fleet…" />}

{/* inline, no overlay */}
<LoadingSpinner inline size="sm" />
```

## Inline in a button

```tsx
<Button content="Saving…" loading />        {/* Button embeds the xs spinner for you */}
<LoadingSpinner inline size="xs" />          {/* or place one yourself */}
```
