# PasswordStrength

A strength meter, an optional requirement checklist, and an optional
confirm-password matcher: all in one controlled component. Pairs with the
`Password` input.

## Mental model

Controlled: feed it the current `value`. Scoring is a **dependency-free
heuristic** (0–4) rewarding length + character variety and penalising
repeats/sequences: swap it via `scorer` (e.g. wrap zxcvbn). Pass `confirmValue`
to turn it into the matcher too; `showRequirements` adds the checklist.

## Quick start

```tsx
import { Password, PasswordStrength, scorePassword } from '@geomak/ui'

<Password label="Password" value={pw} onChange={(e) => setPw(e.target.value)} />
<PasswordStrength value={pw} showRequirements confirmValue={confirm} />

// the scorer is exported for your own gating:
const strongEnough = scorePassword(pw).score >= 3
```
