# EmptyCart

The empty-state for a shopping cart: a configurable illustration with a title,
optional description, and an optional call-to-action. `Cart` renders it by
default when it has no items.

## Mental model

A presentational block with sensible defaults. The default illustration is
line-art tinted from the live theme tokens (`--color-accent`,
`--color-border-strong`), so it adapts to light / dark and any brand override
automatically. Everything is configurable: swap the `illustration` for your own
art (or `null` to hide it), and override `title` / `description` / `action`.

## Quick start

```tsx
import { Cart, EmptyCart, Button } from '@geomak/ui'

// Default: Cart shows <EmptyCart /> automatically when empty
<Cart items={[]} />

// Configured: pass it into Cart's emptyState slot
<Cart
  items={[]}
  emptyState={
    <EmptyCart
      title="No items yet"
      description="Browse the catalog to add equipment."
      action={<Button content="Browse products" variant="secondary" size="sm" />}
    />
  }
/>

// Fully custom illustration
<EmptyCart illustration={<MyBrandArt />} title="Nothing here" />
```
