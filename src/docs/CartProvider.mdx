# Cart Provider

An app-wide cart store. Wrap your tree in `CartProvider` once, then call
`useCart()` from anywhere — a product grid, the cart drawer, a TopBar badge, and
the checkout page all read and mutate the same state with no prop-drilling.

## Mental model

`CartProvider` owns the items array (uncontrolled, seeded by `initialItems`).
Components don't pass the cart around — they pull exactly what they need from
`useCart()`. Mutations are immutable and quantity-safe: `addToCart` merges into
an existing line and every quantity is clamped to `1..max`. Subscribe to changes
via `onChange` to persist (e.g. `localStorage`) or sync to a backend.

`useCart()` throws if called outside a `CartProvider`, so a missing provider
fails loudly in development rather than silently no-op'ing.

## Quick start

```tsx
import { CartProvider, useCart } from '@geomak/ui'

// 1. Provide once, near the root
<CartProvider initialItems={[]} onChange={(items) => save(items)}>
  <App />
</CartProvider>

// 2. Consume anywhere inside
function AddButton({ product }) {
  const { addToCart, isInCart } = useCart()
  return (
    <Button
      content={isInCart(product.id) ? 'Add more' : 'Add to cart'}
      onClick={() => addToCart(product)}
    />
  )
}
```

### CartItemInput

The shape accepted by `addToCart` — a `CartLineItem` with an **optional**
`quantity` (defaults to 1):

```ts
type CartItemInput = Omit<CartLineItem, 'quantity'> & { quantity?: number }
```

## Recipes

**Persist across reloads** — wire `onChange` + `initialItems`:

```tsx
<CartProvider
  initialItems={JSON.parse(localStorage.getItem('cart') ?? '[]')}
  onChange={(items) => localStorage.setItem('cart', JSON.stringify(items))}
>
  <App />
</CartProvider>
```

**Cart count anywhere** — the badge in the TopBar:

```tsx
const { getItemCount } = useCart()
<Badge count={getItemCount()} tone="accent"><CartIcon /></Badge>
```

> `CartButton` already wraps this pattern, and `Checkout` consumes the same
> store. See their guides.
