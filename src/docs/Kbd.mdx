# Kbd

Renders keyboard keys as styled caps: for documenting shortcuts and hints.

## Mental model

Pass a single key as `children`, or a combination as `keys` (each entry becomes
its own `<kbd>` cap, joined by `separator`). The single form renders one `<kbd>`;
the combo form wraps caps in a `<span>`. Inline-friendly: drop it straight into
sentences.

## Quick start

```tsx
import { Kbd } from '@geomak/ui'

<Kbd>Esc</Kbd>
<Kbd keys={['Ctrl', 'K']} />
<Kbd keys={['⌘', '⇧', 'P']} size="sm" />
```

## In running text

```tsx
<p>Press <Kbd keys={['Ctrl', 'K']} size="sm" /> to open the command palette.</p>
```
