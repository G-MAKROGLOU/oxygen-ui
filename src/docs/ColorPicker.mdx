# ColorPicker

A swatch grid + hex field in a popover, with an optional native eyedropper for
arbitrary colors.

## Mental model

Controlled with a hex `string` (`"#0466c8"`). `onChange` reports the next hex.
The popover shows preset `swatches`; `allowCustom` adds a native
`<input type="color">` fallback for picking any value.

## Quick start

```tsx
import { ColorPicker } from '@geomak/ui'

const [color, setColor] = useState('#0466c8')

<ColorPicker label="Brand color" value={color} onChange={setColor} />
```

## With the Form API

```tsx
<ColorPicker label="Color" {...form.field('color', { required: true })} />
```

## Custom swatches

```tsx
<ColorPicker
  label="Color"
  swatches={['#0466c8', '#0353a4', '#023e7d', '#001845', '#33415c']}
  allowCustom={false}            {/* swatches only, no native picker */}
  value={color}
  onChange={setColor}
/>
```
