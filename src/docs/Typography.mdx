# Typography

The type system uses **Inter Variable** — a single font file covering the full weight range without FOUT or multiple HTTP requests. Every value is a CSS custom property, fully overridable.

---

## Font family

```css
--font-family-sans: "Inter var", sans-serif;
```

Override with any variable font:

```css
:root { --font-family-sans: "Geist", sans-serif; }
```

## Overriding the type scale

Scale the entire type system for a denser or more spacious feel:

```css
:root {
  /* Compact scale — shift every step down ~1 size */
  --font-size-xs:   0.6875rem;   /* 11px */
  --font-size-sm:   0.75rem;     /* 12px */
  --font-size-base: 0.875rem;    /* 14px */
  --font-size-lg:   1rem;        /* 16px */
}
```

Or via `ThemeProvider`:

```tsx
<ThemeProvider
  theme={{
    typography: {
      fontFamily:   '"Geist", sans-serif',
      fontSizeBase: '0.875rem',
      fontSizeSm:   '0.75rem',
    }
  }}
>
  <App />
</ThemeProvider>
```
