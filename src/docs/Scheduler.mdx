# Scheduler

An event scheduler with **month** and **week** views — the agenda-style calendar
for dashboards and ops tools. For single-date selection use
[Calendar](/docs/data-display-calendar--docs) (the date-picker grid) instead.

## Mental model

The Scheduler owns the view (`month` / `week`) and the focused date; the toolbar
pages and toggles them. Click the month/year title to open a quick jump picker
(month grid + year stepper) for moving across the calendar fast, rather than
paging one step at a time. Feed it data one of two ways:

- **Controlled** — pass `events` directly (you fetch / manage them).
- **Async** — pass `loadEvents(range, view)`; it's called whenever the visible
  range or view changes, and the Scheduler shows a loading indicator around it.

Events span a `start`–`end` (ISO strings or `Date`s). In **month** view they
render as coloured chips per day (capped, with "+N more"); in **week** view they
sit at their real time, sized by duration, inside a scrollable hour grid.

## Quick start

```tsx
import { Scheduler } from '@geomak/ui'

// Async — fetch per visible range
<Scheduler
  loadEvents={async ({ from, to }) => api.events(from, to)}
  onSelectEvent={(e) => openEvent(e)}
  onNewEvent={() => createEvent()}
/>

// Controlled
<Scheduler events={events} defaultView="week" onSelectSlot={(d) => createAt(d)} />
```
