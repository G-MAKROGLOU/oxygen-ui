# useJwt

Decode a JWT client-side and track its expiry reactively.

> **Decode only — never verification.** The hook reads the token's claims; it
> does not (and cannot) verify the signature. Treat the result as a UI hint;
> real authorization belongs on the server. Pairs naturally with
> [SecureLayout](/docs/layout-securelayout-guide--docs).

## Mental model

`useJwt(token)` decodes the header and payload and derives expiry from the `exp`
claim. It re-renders **exactly when the token crosses its `exp`**, so `isExpired`
/ `isValid` flip on their own without polling. Pass `null` / `undefined` for a
logged-out state and everything reads empty.

## Quick start

```tsx
import { useJwt } from '@geomak/ui'

const { payload, isValid, isExpired, expiresAt } = useJwt<{ sub: string; role: string }>(token)

if (!isValid) redirectToLogin()
```
