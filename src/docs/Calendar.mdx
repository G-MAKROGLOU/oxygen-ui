# Calendar

A month-grid calendar for displaying and picking a day, with optional event dots.
Dependency-free date math.

## Mental model

Controlled selection via `value` + `onChange` (the clicked `Date`). The visible
month is independent: uncontrolled with `defaultMonth`, or controlled with
`month` + `onMonthChange`. `events` render up to three dots beneath a day.
`min`/`max` disable out-of-range days; `weekStartsOn` flips the first column.

This is the **display** calendar — for a popover date *field*, use **Temporal**
(DatePicker), which embeds a calendar like this one.

## Quick start

```tsx
import { Calendar } from '@geomak/ui'

const [day, setDay] = useState<Date | null>(null)

<Calendar value={day} onChange={setDay} />
```

## Events & bounds

```tsx
<Calendar
  value={day}
  onChange={setDay}
  events={[
    { date: new Date(), label: 'Standup', color: 'var(--color-status-info)' },
    { date: addDays(new Date(), 2), label: 'Deploy', color: 'var(--color-status-success)' },
  ]}
  min={rangeStart}
  max={rangeEnd}
  weekStartsOn={1}
/>
```
