# ScalableContainer

A container that smoothly expands to fill its parent on click and collapses back,
with an OS-window aesthetic: a subtle elevation lift, no color flash.

## Mental model

It animates both width and height between a resting size and an expanded size.
Expansion can be **uncontrolled** (click the toggle) or **controlled** via
`expanded` + `onExpandedChange`. The container is transparent by default, so it
overlays whatever surface sits behind it; the shadow lifts on expand like a window
being raised. The floating toggle is absolutely positioned (configurable corner)
so it never pushes layout.

## Quick start

```tsx
import { ScalableContainer } from '@geomak/ui'

<ScalableContainer width={320} height={200} expandedHeight={480}>
  <ChartPanel />
</ScalableContainer>
```

## Controlled

```tsx
const [open, setOpen] = useState(false)

<ScalableContainer
  expanded={open}
  onExpandedChange={setOpen}
  expandedWidth="100%"
  expandedHeight={420}
  togglePosition="top-right"
>
  <DetailView />
</ScalableContainer>
```
