# Accordion

Vertically stacked, collapsible panels on Radix Accordion, with animated height
and full keyboard support.

## Mental model

`Accordion` is **compositional**: the root holds `Accordion.Item` children, each
with a unique `value` and a `title` (the always-visible trigger). `type="single"`
(default) keeps one panel open at a time — `collapsible` lets that one close;
`type="multiple"` allows any number open. Open state is uncontrolled via
`defaultValue` or controlled via `value` + `onValueChange`. Radix supplies the
height var that the `accordion-down` / `accordion-up` keyframes animate.

## Quick start

```tsx
import { Accordion } from '@geomak/ui'

<Accordion type="single" defaultValue="a" collapsible>
  <Accordion.Item value="a" title="What is included?">
    Everything in Starter, plus unlimited projects and priority support.
  </Accordion.Item>
  <Accordion.Item value="b" title="Can I cancel anytime?">
    Yes — cancel from billing settings, no questions asked.
  </Accordion.Item>
</Accordion>
```

## Variants & multiple

```tsx
<Accordion variant="contained">…</Accordion>          {/* one card, divider lines */}

<Accordion type="multiple" defaultValue={['a', 'c']}>  {/* many open at once */}
  <Accordion.Item value="a" icon={<BoltIcon />} title="Performance">…</Accordion.Item>
  <Accordion.Item value="b" title="Security">…</Accordion.Item>
  <Accordion.Item value="c" title="Support" disabled>…</Accordion.Item>
</Accordion>
```

## Controlled

```tsx
const [open, setOpen] = useState('a')
<Accordion type="single" value={open} onValueChange={setOpen}>…</Accordion>
```
