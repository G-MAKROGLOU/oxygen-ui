# DateRangePicker

A start-to-end date range picker with a two-click calendar and optional
quick-select presets (Today, Last 7 days, This month, …).

## Mental model

Controlled with a `DateRange` (`{ start: Date | null, end: Date | null }`).
`onChange` reports the next range. Clicking the calendar sets the start, then the
end. Provide `presets` for one-click ranges.

## Quick start

```tsx
import { DateRangePicker } from '@geomak/ui'

const [range, setRange] = useState({ start: null, end: null })

<DateRangePicker label="Period" value={range} onChange={setRange} />
```

## With the Form API

```tsx
<DateRangePicker label="Period" {...form.field('period', { required: true })} />
```

## Presets & bounds

```tsx
<DateRangePicker
  label="Period"
  presets={[
    { label: 'Last 7 days', range: () => ({ start: addDays(new Date(), -6), end: new Date() }) },
    { label: 'This month',  range: () => ({ start: startOfMonth(new Date()), end: new Date() }) },
  ]}
  min={minDate}
  max={maxDate}
  weekStartsOn={1}
  value={range}
  onChange={setRange}
/>
```
