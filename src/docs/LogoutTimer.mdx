# LogoutTimer

An inactivity / session-timeout guard. After a period of no activity it raises a
warning dialog that counts down to an automatic sign-out: the standard
"You'll be signed out soon" pattern for banking, admin, and CRM apps.

## Mental model

Activity events (mouse, keyboard, touch, scroll) reset an idle timer. After
`timeout` ms idle, a warning Modal appears and counts down for `countdown` ms.
While the warning is up, background activity **does not** reset it: the user
must choose: **Stay signed in** (`onContinue`, idle timer restarts) or **Sign
out now** (`onLogout`). If the countdown reaches zero, `onLogout` fires
automatically. Closing the dialog (Esc / backdrop) counts as staying.

Mount it once near the app root: typically alongside your
[SecureLayout](/docs/layout-securelayout-guide--docs).

## Quick start

```tsx
import { LogoutTimer } from '@geomak/ui'

<LogoutTimer
  timeout={15 * 60_000}   // warn after 15 minutes idle
  countdown={60_000}      // 60 seconds to respond
  onLogout={() => navigate('/logout')}
  onContinue={() => refreshSession()}
/>
```
