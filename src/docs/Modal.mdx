# Modal

A centred dialog powered by Radix Dialog + Framer Motion: focus-trapped,
escape-to-close, scale + fade animation, reduced-motion aware.

## Mental model

Fully **controlled** — you own `open` and close it via `onClose`. The panel is
content-driven in height (max 90 dvh) and capped in width by `width`. The optional
built-in footer renders OK / Cancel buttons wired to `onOk` / `onCancel`; omit it
with `hasFooter={false}` to supply your own actions in `children`.

## Quick start

```tsx
import { Modal } from '@geomak/ui'

const [open, setOpen] = useState(false)

<Modal
  open={open}
  onClose={() => setOpen(false)}
  title="Confirm deletion"
  okText="Delete"
  cancelText="Keep"
  onOk={handleDelete}
>
  This permanently removes the vessel record. This cannot be undone.
</Modal>
```

## Custom footer

```tsx
<Modal open={open} onClose={close} title="Edit profile" hasFooter={false} width={720}>
  <ProfileForm onSaved={close} />
</Modal>
```
