# Badge

A small status / count indicator with three uses: a label pill, an inline
counter, or an overlay anchored to another element.

## Mental model

The presence of `count` or `dot` switches Badge from **label mode** to
**indicator mode**:

- **Label pill** — `children` only: `<Badge tone="success">Active</Badge>`.
- **Inline count** — `count` (or `dot`) without children: `<Badge count={5} />`.
- **Overlay** — `count`/`dot` *with* children: the indicator anchors to the
  child's top-right corner.

`tone` sets the semantic colour; `variant` (solid / soft / outline) the fill.
A zero count hides itself unless `showZero`; large counts cap at `max` (`99+`).

## Quick start

```tsx
import { Badge } from '@geomak/ui'

<Badge tone="success">Active</Badge>
<Badge tone="accent" variant="outline">Beta</Badge>

<Badge count={5} tone="error" />            {/* inline counter */}
<Badge count={1280} max={99} tone="accent" /> {/* shows 99+ */}
```

## Overlay on an element

```tsx
<Badge count={3} tone="error">
  <IconButton icon={<BellIcon />} title="Notifications" />
</Badge>

<Badge dot tone="success">
  <Avatar src={user.photo} alt={user.name} />
</Badge>
```
