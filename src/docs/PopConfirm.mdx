# PopConfirm

A lightweight "are you sure?" prompt anchored to its trigger: for in-place
confirmation without a full Modal.

## Mental model

Wrap the trigger element (it's cloned as the popover anchor). Clicking the trigger
opens a small popover with your `title`, optional `description`, and Confirm /
Cancel buttons. `onConfirm` runs on confirm; if it returns a promise, the confirm
button stays in a loading state until it settles, then closes. `tone="danger"`
colours the confirm button red for destructive actions. Reach for this over Modal
when the decision is small and local (delete a row, archive an item).

## Quick start

```tsx
import { PopConfirm, Button } from '@geomak/ui'

<PopConfirm
  title="Delete this vessel?"
  description="This permanently removes the record."
  tone="danger"
  confirmText="Delete"
  onConfirm={remove}
>
  <Button content="Delete" variant="danger" />
</PopConfirm>
```

## Async confirm

```tsx
<PopConfirm title="Archive this item?" confirmText="Archive" onConfirm={async () => { await archive(id) }}>
  <Button content="Archive" variant="secondary" />
</PopConfirm>
```
