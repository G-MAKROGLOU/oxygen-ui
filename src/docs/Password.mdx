# Password

A password field with a built-in show/hide reveal toggle. Same field foundation
as `TextInput` (label, layout, helperText, error, Halo Focus), full-width by
default.

## Mental model

Controlled like `TextInput` (`value` + `onChange`). The reveal button toggles
the input between `type="password"` and `type="text"`; override its icons with
`showIcon` / `hideIcon`.

## Quick start

```tsx
import { Password } from '@geomak/ui'

const [pw, setPw] = useState('')

<Password label="Password" value={pw} onChange={(e) => setPw(e.target.value)} />
```

## With the Form API

```tsx
<Password
  label="Password"
  {...form.fieldNative('password', { required: true, minLength: { value: 8, message: 'At least 8 characters' } })}
/>
```

## States & customisation

```tsx
<Password label="Password" errorMessage="Too short" value="ab" onChange={…} />
<Password label="Password" disabled value="••••••" onChange={…} />
<Password label="Password" size="lg" layout="horizontal" helperText="Use 8+ characters." … />
<Password label="Password" showIcon={<Eye />} hideIcon={<EyeOff />} … />
```
