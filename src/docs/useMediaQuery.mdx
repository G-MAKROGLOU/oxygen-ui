# useMediaQuery

Track a CSS media query reactively: for responsive logic that lives in JS, not
just CSS.

## Mental model

`useMediaQuery(query)` returns a boolean that updates as the match changes. It's
**SSR-safe**: it returns `false` until mounted (and when `matchMedia` is
unavailable), then syncs on the first effect. `useBreakpoint()` is a convenience
built on top, exposing the library's responsive breakpoints (matching the
Tailwind `screens`) as min-width flags plus the largest matched one.

## Quick start

```tsx
import { useMediaQuery, useBreakpoint } from '@geomak/ui'

const isWide  = useMediaQuery('(min-width: 1024px)')
const reduced = useMediaQuery('(prefers-reduced-motion: reduce)')

const { md, active } = useBreakpoint()
if (!md) return <MobileNav />   // below 768px
```
