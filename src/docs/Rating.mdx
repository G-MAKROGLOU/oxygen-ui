# Rating

A row of star icons for capturing a score, with optional half-star precision and
a read-only display mode.

## Mental model

Controlled with a `number`. `onChange` reports the next value. `count` sets the
number of icons, `allowHalf` enables half-step precision, and `readOnly` renders a
static score (no hover/click). With `clearable`, clicking the current value again
resets to 0.

## Quick start

```tsx
import { Rating } from '@geomak/ui'

const [score, setScore] = useState(0)

<Rating label="Quality" value={score} onChange={setScore} />
```

## With the Form API

```tsx
<Rating label="Rate it" {...form.field('score', { required: true })} />
```

## Half stars & read-only

```tsx
<Rating label="Score" allowHalf value={4.5} onChange={setScore} />
<Rating label="Average" value={3.5} readOnly />            {/* display only */}
```
