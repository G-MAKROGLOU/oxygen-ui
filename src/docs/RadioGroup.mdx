# RadioGroup

A single-select radio group on Radix RadioGroup: arrow-key roving focus,
`role="radiogroup"`, and the shared field foundation. Options support a
secondary `description` and per-option `disabled`.

## Mental model

Driven by an `options` array; the value is the selected option's `value`
(a string). `onChange` reports the value directly. Use `value` + `onChange`
(controlled) or `defaultValue` (uncontrolled). Lay options out vertically
(default) or horizontally, with the label on either side of the dot.

## Quick start

```tsx
import { RadioGroup } from '@geomak/ui'

const [freq, setFreq] = useState('daily')

<RadioGroup
  label="Notification frequency"
  name="freq"
  value={freq}
  onChange={setFreq}
  options={[
    { value: 'realtime', label: 'Real-time', description: 'Notify me immediately' },
    { value: 'daily',    label: 'Daily digest' },
    { value: 'off',      label: 'Off', disabled: true },
  ]}
/>
```

## With the Form API

Bind with `field` (its `onChange` takes the value directly):

```tsx
<RadioGroup label="Plan" options={PLANS} {...form.field('plan', { required: 'Pick a plan' })} />
```

## Layout & label side

```tsx
<RadioGroup layout="horizontal" options={DENSITY} … />          {/* options in a row */}
<RadioGroup labelPosition="left" options={OPTS} … />            {/* label left of the dot */}
<RadioGroup size="lg" options={OPTS} … />                       {/* sm | md | lg */}
<RadioGroup required errorMessage="Please choose" value={undefined} options={OPTS} … />
```
