# RadioTile

A single-select group of rich, card-style options: icon, title, description and
an optional badge. Real radio semantics (built on Radix), so it's keyboard- and
form-friendly.

## Mental model

Like `RadioGroup`, but each option renders as a selectable tile instead of a dot.
Controlled (`value` + `onChange`) or uncontrolled (`defaultValue`). The selected
tile gets an accent border + ring and a check mark. Lay tiles out in 1–3 columns.

## Quick start

```tsx
import { RadioTile } from '@geomak/ui'

<RadioTile
  label="Plan" name="plan" columns={3}
  value={plan} onChange={setPlan}
  options={[
    { value: 'starter', label: 'Starter', description: '1 vessel', icon: <BoltIcon /> },
    { value: 'pro', label: 'Pro', description: 'Unlimited', icon: <SparklesIcon />, badge: 'Popular' },
  ]}
/>
```
