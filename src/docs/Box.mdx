# Box

The polymorphic layout primitive. A token-styled `<div>` (or any element via
`as`) that replaces ad-hoc `className="p-4 bg-surface border rounded-lg"`.

## Mental model

Box maps prop shortcuts to the design system's token scales — spacing (padding /
margin), background, border, radius, shadow — emitting Tailwind classes so there's
no runtime style cost. Spacing props take the shared scale (`none`→`2xl`). Use
`as` when the semantic element should differ from a `div`.

## Quick start

```tsx
import { Box } from '@geomak/ui'

<Box p="lg" background="surface" border="border" radius="lg" shadow="sm">
  <Typography variant="h3">Card title</Typography>
</Box>

<Box as="section" px="md" py="lg" background="background">
  <PageContent />
</Box>
```
