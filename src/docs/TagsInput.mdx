# TagsInput

A free-text field that collects entries as removable chips. Type and press Enter
(or comma) to add; Backspace on an empty field removes the last tag.

## Mental model

Controlled with a `string[]`. `onChange` reports the next array. Each committed
entry becomes a chip with its own remove affordance. The text field itself is
internal; you only manage the list.

## Quick start

```tsx
import { TagsInput } from '@geomak/ui'

const [tags, setTags] = useState<string[]>(['urgent'])

<TagsInput label="Labels" placeholder="Add a label…" value={tags} onChange={setTags} />
```

## With the Form API

```tsx
<TagsInput label="Labels" {...form.field('labels', { required: 'Add at least one' })} />
```
