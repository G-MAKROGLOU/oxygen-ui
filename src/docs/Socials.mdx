# Socials

A row of social / contact icon links: for footers, headers, author bios and
contact sections.

## Mental model

Each link either names a `platform` (built-in brand glyph + default label) or
supplies a custom `icon`. Every link is a focusable, labelled anchor; external
links open in a new tab (`mailto:` never does). Three button treatments none
`ghost`, `solid`, `outline`.

Built-in platforms: `x`, `twitter`, `github`, `linkedin`, `youtube`,
`instagram`, `facebook`, `mastodon`, `email`, `website`.

## Quick start

```tsx
import { Socials } from '@geomak/ui'

<Socials variant="outline" links={[
  { platform: 'github', href: 'https://github.com/acme' },
  { platform: 'linkedin', href: 'https://linkedin.com/company/acme' },
  { platform: 'email', href: 'mailto:hi@acme.com' },
  { icon: <MyIcon />, href: 'https://acme.dev', label: 'Dev blog' },  // custom
]} />
```
