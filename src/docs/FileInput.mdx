# FileInput

A click-or-drag dropzone that collects files as a list, with `accept` filtering,
a `maxSize` guard, and per-file remove.

## Mental model

`onChange` is **target-shaped**: it fires with `{ target: { files, name, id } }`,
where `files` is a `File[]`. The component keeps the selected files internally and
renders them as a list; you read the array off `e.target.files`. This shape exists
so it slots straight into native-style form handlers.

## Quick start

```tsx
import { FileInput } from '@geomak/ui'

const [files, setFiles] = useState<File[]>([])

<FileInput
  label="Attachments"
  allowMultiple
  accept=".pdf,.xlsx"
  hint="PDF or Excel, up to 10 MB"
  maxSize={10 * 1024 * 1024}
  onChange={(e) => setFiles(e.target.files)}
/>
```

## With the Form API

FileInput binds **manually** (its `onChange` is target-shaped, not value-shaped):

```tsx
<FileInput
  label="Attachments"
  onChange={(e) => form.setValue('attachments', e.target.files)}
  errorMessage={form.errors.attachments}
/>
```
