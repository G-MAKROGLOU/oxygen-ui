# Avatar

A circular (or rounded-square) user avatar built on Radix Avatar, with graceful
image-load fallback and an optional presence dot.

## Mental model

Give it a `src`; Radix manages the load lifecycle and swaps in `fallback` if the
image is missing or fails to decode. `fallback` can be initials (a string,
rendered semi-bold), any node (icon/emoji), or omitted for a generic silhouette.
`status` adds a presence dot in the corner.

## Quick start

```tsx
import { Avatar } from '@geomak/ui'

<Avatar src="/crew/jdoe.jpg" alt="Jane Doe" fallback="JD" status="online" />
<Avatar fallback="AB" size="lg" shape="square" />
<Avatar alt="Unknown user" />              {/* silhouette fallback */}
```
