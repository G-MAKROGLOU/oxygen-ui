# Skeleton

Shimmering placeholders that hold layout while content loads. Four shapes —
`SkeletonBox`, `SkeletonText`, `SkeletonCircle`, `SkeletonCard` — compose into any
loading view.

## Mental model

Each primitive is a themed placeholder. The animated sweep is `color-mix`-ed from
the foreground token, so it stays visible in both light and dark; the resting
color is `surface-raised` and overridable via `className`/`style`. Reduced-motion
hides the sweep but keeps the legible base. Mirror your real content's shape so
nothing jumps when data arrives.

## Quick start

```tsx
import { SkeletonBox, SkeletonText, SkeletonCircle, SkeletonCard } from '@geomak/ui'

{loading ? (
  <SkeletonCard hasAvatar lines={3} />
) : (
  <ProfileCard user={user} />
)}
```

## Composing a custom placeholder

```tsx
<div className="flex gap-3">
  <SkeletonCircle size={48} />
  <div className="flex-1">
    <SkeletonText lines={2} />
    <SkeletonBox width="60%" height={12} />
  </div>
</div>
```
