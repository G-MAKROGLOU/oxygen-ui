# FeatureGrid

A responsive grid of product features — icon, title, blurb — with an optional
section header.

## Quick start

```tsx
import { FeatureGrid } from '@geomak/ui'

<FeatureGrid
  eyebrow="Platform"
  title="Everything in one portal"
  columns={3}
  features={[
    { icon: <BoltIcon />, title: 'Real-time', description: 'Live vessel data.' },
    { icon: <ShieldIcon />, title: 'Compliance', description: 'CII / AER / EU-ETS.' },
  ]}
/>
```

Collapses to one column on mobile; `columns` (2 / 3 / 4) sets the widest layout.
Each feature icon sits in an accent-tinted tile.
