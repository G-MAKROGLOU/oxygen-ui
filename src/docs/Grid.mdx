# Grid

`Box` with `display: grid` baked in. Use `cols`/`rows` as numbers for the common
"N equal tracks" case, or pass any CSS `grid-template-*` string for arbitrary
layouts.

## Mental model

Pass `cols={3}` for three equal columns, or `cols="200px 1fr"` /
`cols="repeat(auto-fit, minmax(220px, 1fr))"` for explicit tracks. `gap` (or
`gapX`/`gapY`) uses the token spacing scale. Inherits every Box prop, so the
container's surface and padding live on the same element.

## Quick start

```tsx
import { Grid } from '@geomak/ui'

<Grid cols={3} gap="md">
  <Card /><Card /><Card />
</Grid>

{/* responsive auto-fit */}
<Grid cols="repeat(auto-fit, minmax(220px, 1fr))" gap="lg">
  {items.map((it) => <Card key={it.id} {...it} />)}
</Grid>
```
