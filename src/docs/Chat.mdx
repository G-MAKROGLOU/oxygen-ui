# Chat

A messaging surface: a scrollable transcript of message bubbles plus a composer.

## Mental model

Chat is **controlled** — you own the `messages` array; the composer reports text
via `onSend` (you append and re-render). Each message carries an `authorId`;
those matching `currentUserId` align right in the accent colour, everyone else
aligns left on a raised surface with an avatar (image or initials of
`authorName`) and name. Consecutive messages from one author **group** (one
avatar + name per group, timestamp on the last bubble). The list **auto-scrolls**
to the newest message unless you've scrolled up to read history, in which case a
"jump to latest" button appears. `typingNames` shows an animated indicator.

## Quick start

```tsx
import { Chat, type ChatMessage } from '@geomak/ui'

const [messages, setMessages] = useState<ChatMessage[]>(initial)

<Chat
  currentUserId="me"
  title="Maria Ferreira"
  subtitle="Online"
  messages={messages}
  typingNames={typing}            // e.g. ['Maria']
  onSend={(text) => {
    setMessages((m) => [...m, { id: uid(), authorId: 'me', text, timestamp: new Date(), status: 'sent' }])
  }}
/>
```

Enter sends; Shift+Enter inserts a newline. Use `hideComposer` for a read-only
transcript.
