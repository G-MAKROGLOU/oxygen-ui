# Cart

A shopping-cart panel: line items with thumbnail, quantity stepper, and remove,
plus a totalled summary and an optional checkout button.

## Mental model

Cart is **stateless and controlled** — you own the `items` array and react to
`onQuantityChange` (clamped to `1..max`) and `onRemove`. It computes the subtotal
from `price × quantity`; `summaryRows` (shipping, tax, discount — use a negative
value for discounts) are added on top for the total. `formatPrice` overrides the
default `$0.00` formatting. With no items it shows `emptyState`.

## Quick start

```tsx
import { Cart } from '@geomak/ui'

const [items, setItems] = useState(initialItems)

<Cart
  items={items}
  onQuantityChange={(id, q) => setItems((p) => p.map((it) => it.id === id ? { ...it, quantity: q } : it))}
  onRemove={(id) => setItems((p) => p.filter((it) => it.id !== id))}
  summaryRows={[
    { label: 'Shipping', value: 24 },
    { label: 'Promo (SAVE10)', value: -50, muted: true },
  ]}
  onCheckout={checkout}
/>
```
