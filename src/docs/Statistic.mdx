# Statistic

A single metric: caption, value (with optional prefix/suffix and icon), and an
optional trend delta.

## Mental model

Give it a `label` and a `value`. `prefix`/`suffix` frame the value (currency,
unit, %). The optional `delta` shows a trend with an arrow; its colour follows
`direction`, but you can invert the good/bad mapping with `positiveIsGood: false`
for metrics where a rise is bad (churn, latency, error rate). Compose several
inside `Card`s for a metrics row.

## Quick start

```tsx
import { Statistic } from '@geomak/ui'

<Statistic
  label="Revenue"
  value="48,210"
  prefix="$"
  delta={{ value: '12%', direction: 'up', label: 'vs last month' }}
/>
```

## Inverted trend (a rise is bad)

```tsx
<Statistic
  label="Churn rate"
  value="3.1"
  suffix="%"
  delta={{ value: '0.4pt', direction: 'up', positiveIsGood: false }}
/>
```
