# ThemeSwitch

A dark-mode toggle built on Radix Switch. The thumb color signals the mode: green
in light, slate in dark.

## Mental model

A controlled switch: you own `checked` (true = dark) and react to `onChange`,
which is **target-shaped** — `{ target: { checked } }` — so it drops into native
form handlers. The switch itself only reports intent; you decide what to do with
it, typically toggling `.dark` on a `ThemeProvider` running `colorScheme="auto"`.
It renders inline with no external margins; layout is the parent's job.

## Quick start

```tsx
import { ThemeSwitch } from '@geomak/ui'

const [dark, setDark] = useState(false)

<ThemeSwitch checked={dark} onChange={({ target }) => setDark(target.checked)} />
```

## Driving the theme

```tsx
function Shell() {
  const [dark, setDark] = useState(false)
  return (
    <ThemeProvider colorScheme={dark ? 'dark' : 'light'}>
      <TopBar actions={<ThemeSwitch checked={dark} onChange={({ target }) => setDark(target.checked)} />} />
      <App />
    </ThemeProvider>
  )
}
```
