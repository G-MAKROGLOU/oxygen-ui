# ThemeProvider

The root that injects design tokens as CSS variables and manages light/dark mode.
Wrap your app once.

## Mental model

ThemeProvider writes the design tokens (colors, radius, shadows, typography,
density, motion) as CSS custom properties on its wrapper, so every component reads
them at runtime. `theme` overrides tokens in both modes; `darkTheme` layers
dark-only overrides via a scoped `<style>` on the `.dark` class. `colorScheme`
controls how that class is applied:

- `'light'` / `'dark'`: force the mode
- `'system'`: follow `prefers-color-scheme`
- `'auto'` (default): inherit from an ancestor (you toggle `.dark` yourself, e.g. via ThemeSwitch)

## Quick start

```tsx
import { ThemeProvider } from '@geomak/ui'

<ThemeProvider colorScheme="system">
  <App />
</ThemeProvider>
```

## Brand token overrides

```tsx
<ThemeProvider
  theme={{
    colors: { accent: '#0466c8' },
    radius: { md: 10 },
  }}
  darkTheme={{
    colors: { background: '#0b1220', surface: '#121a2b' },
  }}
  colorScheme="auto"
>
  <App />
</ThemeProvider>
```
