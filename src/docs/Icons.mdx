# Icons

A cohesive pack of SVG icons that colour with `currentColor`, size in pixels,
and are accessible by default. Browse them all in **Icons → Gallery** (click any
icon to copy its usage).

## Mental model

Every icon is a small React component drawn on a 24×24 grid. It has **no hard-coded
colour or size** — it inherits the surrounding text colour via `currentColor`
and defaults to 24px. Most icons are outline (stroked); a few are solid (carets,
dots, `StarFilled`). Icons are **decorative by default** (`aria-hidden`); pass a
`title` only when the icon is the sole meaning of a control.

Icons live under the **`Icon` namespace** so they never clash with component
names (there's both a `Table` component and a `Table` icon):

```tsx
import { Icon } from '@geomak/ui'

<Icon.Search />                                    // 24px, inherits text colour
<Icon.Trash size={20} className="text-status-error" title="Delete" />
<button className="text-accent"><Icon.Plus /></button>   // follows the button colour
```

## Colour & size

Because icons use `currentColor`, set colour with a text utility on the icon or
any ancestor:

```tsx
<Icon.Heart className="text-accent" />
<span className="text-status-success"><Icon.CheckCircle /></span>
```

Size is a pixel number (or any CSS length). Outline icons accept `strokeWidth`
(default `1.5`):

```tsx
<Icon.Bell size={32} />
<Icon.Settings size={28} strokeWidth={2} />
```

The `Spinner` icon is static markup — add `className="animate-spin"` to rotate it.

## Extending the pack

Use `createIcon(name, content, options?)` to make your own icons that match the
built-ins exactly — same sizing, `currentColor`, ref forwarding, and a11y. Draw
the artwork on a 24×24 grid (or set a custom `viewBox`).

```tsx
import { createIcon } from '@geomak/ui'

// Outline (default): paths use stroke="currentColor", round caps/joins.
const Anchor = createIcon('Anchor',
  <path d="M12 21V8m0 0a3 3 0 1 0 0-6 3 3 0 0 0 0 6Zm-7 4a7 7 0 0 0 14 0M3 11h4m10 0h4" />)

// Solid: fill="currentColor".
const Pin = createIcon('Pin', <path d="M12 2 4 9v13h16V9z" />, { solid: true })

<Anchor size={32} className="text-accent" title="Anchor" />
```

## Back-compat aliases

Earlier names still resolve to their current equivalents, so existing call sites
keep working: `XClose`→`X`, `Checked`→`Check`, `Cog`→`Settings`, `Tweak`→`Sliders`,
`Expand`→`Maximize`, `Collapse`→`Minimize`, `ShowMore`→`DotsVertical`,
`Delete`→`Trash`, `Bookmarks`→`Bookmark`, `CircleStack`/`Data`→`Database`,
`DoubleChevronRight`→`ChevronsRight`, `Loading`→`Spinner`, `PowerOff`→`Power`.
