# Flex

`Box` with `display: flex` baked in. Inherits every Box prop (padding, margin,
background, border…) and adds flex controls.

## Mental model

A flexbox container with token-scale `gap` and ergonomic enums for `direction`,
`align`, `justify`, and `wrap`. Because it extends Box, you style the container's
surface and spacing on the same element, no wrapper needed.

## Quick start

```tsx
import { Flex } from '@geomak/ui'

<Flex direction="row" align="center" gap="md">
  <Avatar src={user.photo} alt={user.name} />
  <Typography variant="body">{user.name}</Typography>
</Flex>

<Flex direction="col" gap="sm" p="lg" background="surface" radius="lg">
  <Field />
  <Field />
</Flex>
```
