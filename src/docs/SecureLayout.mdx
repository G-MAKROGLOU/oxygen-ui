# SecureLayout

A layout wrapper that gates its children behind an access check —
authentication, RBAC (roles), PBAC (permissions), JWT expiry, and/or a custom
(optionally async) predicate.

> **This is a UI guard, not a security boundary.** It controls what renders.
> Real authorization must be enforced by your API/server — never trust a
> client-side check. The JWT is only inspected for expiry; its signature is
> **not** verified here.

## Mental model

The check runs in an effect (so async predicates are supported). While it
resolves, the `loadingFallback` shows; on success the children fade in; on
failure the `fallback` renders and `onDeny` fires (e.g. to redirect). The gates
are evaluated in order and **all** must pass:

1. **Authenticated** — `isAuthenticated`, or inferred from `token` validity, or assumed true if neither is given.
2. **Roles (RBAC)** — `requiredRoles` against `roles` (any, or all with `requireAllRoles`).
3. **Permissions (PBAC)** — `requiredPermissions` against `permissions` (any, or all with `requireAllPermissions`).
4. **`canAccess()`** — the final say; may be async.

Every prop except `children` is optional — use as much or as little as you need.
The two ends of the spectrum:

## Simple — JWT-only bootstrap (no roles/permissions)

The common case: on load, validate the JWT, hydrate app state from the server,
then land the user. Everything custom goes in `canAccess`; `onGranted` /
`onDeny` handle the navigation. Synchronous gates resolve on the first render
(no spinner flash); `fallback={null}` avoids a panel flashing while you redirect.

```tsx
import { SecureLayout } from '@geomak/ui'

<SecureLayout
  canAccess={async () => {
    const jwt = localStorage.getItem('jwt')
    if (!jwt) return false
    await tokenLogin(jwt)              // validate + hydrate app state
    return true
  }}
  onGranted={() => navigate('/dashboard')}
  onDeny={() => navigate('/logout')}
  fallback={null}
>
  <AppRoutes />
</SecureLayout>
```

Even simpler — gate purely on a token's validity:

```tsx
<SecureLayout token={jwt} onDeny={() => navigate('/login')}>
  <App />
</SecureLayout>
```

## Full — RBAC + PBAC gate

```tsx
<SecureLayout
  token={jwt}
  roles={user.roles}            requiredRoles={['admin']}
  permissions={user.perms}      requiredPermissions={['reports:read']}
  onDeny={() => navigate('/login')}
>
  <AdminDashboard />
</SecureLayout>
```
