# Jumbotron

The landing-page hero: an eyebrow, a large headline, a supporting line, and CTAs
— optionally paired with media.

## Mental model

Content goes in slots so you stay in control: `eyebrow` (a kicker / `Badge`),
`title`, `description`, `actions` (your `Button`s), and `media`. `layout`
switches between `centered` (everything stacked and centred, media below) and
`split` (copy beside the media, stacking on mobile). `background` adds a raised
surface or a soft accent gradient glow. Compose it with FeatureGrid /
PricingPlans / Testimonials for a full page.

## Quick start

```tsx
import { Jumbotron, Button, Badge } from '@geomak/ui'

<Jumbotron
  background="gradient"
  eyebrow={<Badge tone="accent">New</Badge>}
  title="Ship maritime ops faster"
  description="One portal for compliance, performance and voyage data."
  actions={<><Button content="Get started" /><Button variant="outline" content="Book a demo" /></>}
/>
```
