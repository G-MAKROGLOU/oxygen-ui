# MegaMenu

A horizontal navigation bar whose top-level items open wide "mega" dropdown
panels of grouped links. Built on `@radix-ui/react-navigation-menu`, so
hover-intent opening, arrow-key navigation, and focus management all come for
free. Each panel positions itself under the bar and its sections spread across a
content-sized grid. Below the `md` breakpoint the whole bar collapses into a
tap-friendly hamburger accordion.

## Mental model

`MegaMenu` is **compositional**. The bar holds top-level items; each item is
either a **panel item** (opens a dropdown) or a **plain link**.

- `MegaMenu.Item label`: a top-level entry. With children → opens a panel.
  With only `href` → a plain top-level link.
- `MegaMenu.Panel`: the dropdown layout (a grid of sections + an optional
  featured column).
- `MegaMenu.Section title`: a titled column of links.
- `MegaMenu.Link`: a rich link: icon (in a tinted square) + title +
  description.
- `MegaMenu.Featured`: a highlighted promo column (raised surface).

The library is **router-agnostic**: links take `href` and/or `onClick`. Wire
them to your router (e.g. wrap with your `<Link>` or call `navigate` in
`onClick`).

## Quick start

```tsx
import { MegaMenu } from '@geomak/ui'

<MegaMenu aria-label="Main">
  <MegaMenu.Item label="Products">
    <MegaMenu.Panel columns={2}>
      <MegaMenu.Section title="Platform">
        <MegaMenu.Link href="/analytics" icon={<ChartIcon />} description="Dashboards & reports">
          Analytics
        </MegaMenu.Link>
        <MegaMenu.Link href="/streams" icon={<BoltIcon />} description="Real-time events">
          Streams
        </MegaMenu.Link>
      </MegaMenu.Section>
      <MegaMenu.Section title="Operations">
        <MegaMenu.Link href="/security" icon={<ShieldIcon />} description="Policies & audit" active>
          Security
        </MegaMenu.Link>
      </MegaMenu.Section>
    </MegaMenu.Panel>
  </MegaMenu.Item>

  <MegaMenu.Item label="Docs" href="/docs" icon={<BookIcon />} />
  <MegaMenu.Item label="Pricing" href="/pricing" />
</MegaMenu>
```

## A featured (promo) column

`MegaMenu.Featured` sits beside the sections as a raised callout. Fill it with
anything (heading, copy, a CTA).

```tsx
<MegaMenu.Item label="Solutions">
  <MegaMenu.Panel>
    <MegaMenu.Section title="By industry">
      <MegaMenu.Link href="/maritime" icon={<CubeIcon />} description="Vessel tracking">Maritime</MegaMenu.Link>
      <MegaMenu.Link href="/energy" icon={<BoltIcon />} description="Grid monitoring">Energy</MegaMenu.Link>
    </MegaMenu.Section>
    <MegaMenu.Featured>
      <span className="text-[11px] font-semibold uppercase tracking-widest text-accent">New</span>
      <h4 className="mt-1 text-sm font-semibold text-foreground">Fleet Intelligence</h4>
      <p className="mt-1 text-xs text-foreground-secondary flex-1">Predictive maintenance in one console.</p>
      <a href="/fleet" className="mt-3 text-sm font-medium text-accent hover:text-accent-hover">Explore →</a>
    </MegaMenu.Featured>
  </MegaMenu.Panel>
</MegaMenu.Item>
```

## Panel width

Each panel lays its sections out on a grid with a *definite* width, so sections
spread to fill rather than shrink-wrapping to their text. By default a panel is
`min(92vw, 760px)` wide and auto-fits its sections into equal columns. Set
`columns` (1–4) to pin the column count and width: useful when you want a tidy
two-up or three-up layout:

```tsx
<MegaMenu.Panel columns={2}>…</MegaMenu.Panel>   {/* two equal columns */}
<MegaMenu.Panel>…</MegaMenu.Panel>               {/* auto-fit, spreads wide */}
```

## Responsive (mobile fallback)

Hover-driven mega panels don't work on touch, so below the `md` breakpoint
`MegaMenu` automatically swaps the bar for a hamburger **disclosure**: a vertical
accordion built from the very same items (panel items expand in place; plain
links navigate directly). No extra markup: it reads your compound children and
re-renders them as plain anchors.

```tsx
<MegaMenu aria-label="Main" mobileLabel="Browse">…</MegaMenu>

{/* opt out: keep the desktop bar at every width (you provide your own mobile nav) */}
<MegaMenu responsive={false}>…</MegaMenu>
```

## Alignment

Where panels align under the bar: `align="start"` (default), `"center"`, or
`"end"`. Tune the hover-open delay with `delayDuration` (ms).

```tsx
<MegaMenu align="center" delayDuration={120}>…</MegaMenu>
```

## Keyboard & accessibility

Give `MegaMenu` an `aria-label`. Radix provides: Tab to focus the bar, ← / →
between top-level items, Enter / Space or ↓ to open a panel, arrow keys within
the panel, and Esc to close. Mark the current route with `active` on the
relevant `MegaMenu.Link` (and `MegaMenu.Item` for a plain link) so it reads as
selected. The panel honours `prefers-reduced-motion`.
