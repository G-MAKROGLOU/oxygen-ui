# Tooltip

A hover/focus tooltip on Radix Tooltip, animating in from the correct edge per
placement. Keyboard and pointer accessible out of the box.

## Mental model

Wrap the trigger element; the tooltip's content is `title`. Radix manages
show/hide, Escape, pointer + focus triggers, and ARIA. For an app with many
tooltips, wrap once in `TooltipProvider` (re-exported) so they share one provider
and a single open-delay timing instead of nesting one each.

## Quick start

```tsx
import { Tooltip, TooltipProvider } from '@geomak/ui'

<TooltipProvider>
  <Tooltip title="Delete record" placement="top">
    <IconButton icon={<TrashIcon />} />
  </Tooltip>
</TooltipProvider>
```

## Placement & timing

```tsx
<Tooltip title="Appears to the right" placement="right" delayDuration={150} sideOffset={10}>
  <span>Hover me</span>
</Tooltip>
```
