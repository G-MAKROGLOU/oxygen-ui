# LeadCapture

A footer call-to-action band with an inline email-capture form — title,
supporting copy, an email field and a submit button.

## Mental model

A self-contained section: it owns the email field state and, on submit, fires
`onSubmit(email)` then swaps the form for `successMessage`. The field is a real
`type="email"` input (browser validation + an accessible label). `background`
adds a soft accent glow or stays flat on the surface.

## Quick start

```tsx
import { LeadCapture } from '@geomak/ui'

<LeadCapture
  title="Stay in the loop"
  description="Product updates and maritime insights, monthly."
  buttonLabel="Subscribe"
  note="We respect your inbox. Unsubscribe anytime."
  onSubmit={(email) => subscribe(email)}
/>
```
