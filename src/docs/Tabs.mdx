# Tabs

Switch between sibling content panes. The active tab is marked by a thin cobalt
indicator that **slides** between tabs like a needle settling on a gauge, never a
heavy full-fill pill. Built on Radix Tabs, so roving-tabindex keyboard nav,
`role="tablist"`/`tab`/`tabpanel`, and reduced-motion all come for free.

## Mental model

`Tabs` is **compositional**: the root holds the active value + shared options
(variant, size, orientation), and you assemble the parts yourself:

- `Tabs.List`: the strip. Owns overflow (scroll + fade + chevrons + a "jump to
  any tab" menu) and the sliding marker context.
- `Tabs.Trigger value`: one tab button. Self-registers so the overflow menu can
  list it.
- `Tabs.Panel value`: the matching content pane. Lazy by default; mounts on
  first activation.
- `Tabs.Add`: an optional trailing "+" affordance for dynamic tabs.

A `Trigger` and its `Panel` are paired by `value`. Provide `defaultValue`
(uncontrolled) or `value` + `onChange` (controlled).

## Quick start

```tsx
import { Tabs } from '@geomak/ui'

<Tabs defaultValue="overview">
  <Tabs.List aria-label="Sections">
    <Tabs.Trigger value="overview">Overview</Tabs.Trigger>
    <Tabs.Trigger value="activity">Activity</Tabs.Trigger>
    <Tabs.Trigger value="settings">Settings</Tabs.Trigger>
  </Tabs.List>

  <Tabs.Panel value="overview">…</Tabs.Panel>
  <Tabs.Panel value="activity">…</Tabs.Panel>
  <Tabs.Panel value="settings">…</Tabs.Panel>
</Tabs>
```

## Variants

Set `variant` on the root. The marker animates (exponential ease-out, reduced
motion → instant) in `underline` and `segmented`.

```tsx
// Underline (default, signature): sliding cobalt marker under the active tab.
<Tabs defaultValue="a" variant="underline">…</Tabs>

// Segmented: a lifted-pill track for 2–4 compact options; the pill slides.
<Tabs defaultValue="day" variant="segmented">
  <Tabs.List aria-label="Range">
    <Tabs.Trigger value="day">Day</Tabs.Trigger>
    <Tabs.Trigger value="week">Week</Tabs.Trigger>
    <Tabs.Trigger value="month">Month</Tabs.Trigger>
  </Tabs.List>
  <Tabs.Panel value="day">…</Tabs.Panel>
  {/* … */}
</Tabs>

// Enclosed: folder tabs. The active tab is a raised surface that joins the
// panel: wrap the panels in a bordered, top-flush container.
<Tabs defaultValue="editor" variant="enclosed">
  <Tabs.List aria-label="Workspace">
    <Tabs.Trigger value="editor">Editor</Tabs.Trigger>
    <Tabs.Trigger value="preview">Preview</Tabs.Trigger>
  </Tabs.List>
  <div className="rounded-b-lg border border-t-0 border-border bg-surface p-5">
    <Tabs.Panel value="editor">…</Tabs.Panel>
    <Tabs.Panel value="preview">…</Tabs.Panel>
  </div>
</Tabs>
```

## Orientation & size

```tsx
// Vertical rail + panel beside it. Triggers left-align and fill the rail.
<Tabs defaultValue="profile" orientation="vertical">
  <Tabs.List aria-label="Account">
    <Tabs.Trigger value="profile">Profile</Tabs.Trigger>
    <Tabs.Trigger value="alerts">Alerts</Tabs.Trigger>
  </Tabs.List>
  <Tabs.Panel value="profile">…</Tabs.Panel>
  <Tabs.Panel value="alerts">…</Tabs.Panel>
</Tabs>

// Sizes: sm | md (default) | lg.
<Tabs defaultValue="a" size="lg">…</Tabs>
```

## Icons & count badges

```tsx
<Tabs.Trigger value="overview" icon={<HomeIcon />}>Overview</Tabs.Trigger>
<Tabs.Trigger value="activity" badge={12}>Activity</Tabs.Trigger>
<Tabs.Trigger value="archived" disabled>Archived</Tabs.Trigger>
```

The badge is a subtle, theme-relative chip (slate pill + near-white text) that
self-inverts in dark mode.

## Dynamic tabs (closeable + add)

Compose the tab list from your own state; `Tabs.Trigger closeable` renders an ×,
and `Tabs.Add` a trailing "+".

```tsx
function Workspace() {
  const [tabs, setTabs] = useState([{ key: 't1', title: 'Aurora' }])
  const [active, setActive] = useState('t1')
  const [seq, setSeq] = useState(2)

  const close = (key) => setTabs((p) => {
    const next = p.filter((t) => t.key !== key)
    if (key === active && next.length) setActive(next[next.length - 1].key)
    return next
  })
  const add = () => {
    const key = `t${seq}`
    setTabs((p) => [...p, { key, title: `Vessel ${seq}` }])
    setActive(key); setSeq((s) => s + 1)
  }

  return (
    <Tabs value={active} onChange={setActive}>
      <Tabs.List aria-label="Open vessels">
        {tabs.map((t) => (
          <Tabs.Trigger key={t.key} value={t.key} closeable onClose={() => close(t.key)}>
            {t.title}
          </Tabs.Trigger>
        ))}
        <Tabs.Add onClick={add} />
      </Tabs.List>
      {tabs.map((t) => <Tabs.Panel key={t.key} value={t.key}>…</Tabs.Panel>)}
    </Tabs>
  )
}
```

## Overflow

When the strip is too narrow for its tabs it scrolls (drag / wheel / swipe), the
edges fade, and prev/next chevrons appear **only on the overflowing side**. A
**"Show all tabs" (⋯) menu** also appears: hover or click it to jump straight to
any tab. The picked (or keyboard-activated) tab scrolls into view automatically.
No configuration needed.

## Lazy vs. kept-mounted panels

```tsx
// Default: panels mount on first activation (lazy).
<Tabs.Panel value="a">…</Tabs.Panel>

// keepMounted: render even when inactive (preserves scroll / form state).
<Tabs.Panel value="a" keepMounted>…</Tabs.Panel>
```

### `<Tabs.List>` / `<Tabs.Add>`

`Tabs.List` takes `aria-label` (recommended) + `className`. `Tabs.Add` takes
`onClick`, `aria-label` (default "Add tab"), and `className`.

```ts
import { Tabs } from '@geomak/ui'
import type { TabsProps, TabsTriggerProps, TabsPanelProps, TabsListProps, TabsAddProps, TabsVariant, TabsSize, TabsOrientation } from '@geomak/ui'
```
