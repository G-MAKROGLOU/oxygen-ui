# ContextMenu

A right-click menu built on Radix Context Menu, with nested sub-menus, full
keyboard support, and viewport-edge-aware positioning.

## Mental model

Wrap the element that should respond to right-click; its entire subtree becomes
the trigger area. The menu itself is **data-driven** from `items` — each is a
`{ key, value, icon?, onClick? }`, and any item may carry `children` to become a
sub-menu (its own `onClick` is then ignored). Radix owns positioning, focus,
portalling, and keyboard nav (↑↓ move, → opens sub-menu, ← closes, Enter
activates, Esc dismisses).

## Quick start

```tsx
import { ContextMenu } from '@geomak/ui'
import { Pencil, Trash } from 'lucide-react'

<ContextMenu
  items={[
    { key: 'edit',   value: 'Edit',   icon: <Pencil />, onClick: () => openEditor() },
    { key: 'delete', value: 'Delete', icon: <Trash />,  onClick: () => askDelete(), disabled: locked },
  ]}
>
  <VesselCard vessel={vessel} />
</ContextMenu>
```

## Nested sub-menus

```tsx
<ContextMenu
  items={[
    {
      key: 'export', value: 'Export',
      children: [
        { key: 'csv',  value: 'as CSV',   onClick: exportCsv },
        { key: 'xlsx', value: 'as Excel', onClick: exportXlsx },
      ],
    },
  ]}
>
  <Table rows={rows} />
</ContextMenu>
```
