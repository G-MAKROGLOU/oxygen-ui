# Portal

An SSR-safe DOM relocator. Renders children at a detached node (by default
`document.body`) so a `position: fixed` descendant resolves against the real
viewport.

## Mental model

Per the CSS spec, any ancestor with `transform`, `filter`, `perspective`,
`will-change`, or `contain` becomes the containing block for fixed descendants —
silently breaking overlays, toasts, and drawers. Portal escapes that by mounting
its children on `document.body` (or a target you choose), making them immune to
ancestor styling. It renders `null` during SSR and the first client render, then
mounts post-effect.

## When to use

- Full-screen overlays, toast viewports, drawers, loading screens, command palettes, lightboxes.
- Not for inline content that flows naturally, or accessibility-critical content that depends on DOM proximity.
- If you already use a Radix primitive, prefer its built-in `*.Portal`.

## Quick start

```tsx
import { Portal } from '@geomak/ui'

<Portal>
  <div className="fixed inset-0 z-overlay flex items-center justify-center bg-black/40">
    <Spinner />
  </div>
</Portal>
```

## Targeting & disabling

```tsx
{/* mount into a specific node */}
<Portal target={() => document.getElementById('app-root')}>
  <Drawer />
</Portal>

{/* conditionally render inline (no portal) */}
<Portal target={shouldPortal ? undefined : null}>
  <Banner />
</Portal>
```
