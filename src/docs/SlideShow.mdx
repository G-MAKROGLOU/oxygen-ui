# SlideShow

A full-bleed hero carousel. Each slide carries an eyebrow, title, description and
CTAs over an optional background image (with a legibility scrim).

## Mental model

Pass an array of `slides`; the component cross-fades between them, auto-advances
(pausing on hover), and renders arrows + dots. A slide with an `image` gets a
dark scrim and light text; without one it falls back to the surface background
with foreground text. `prefers-reduced-motion` disables the fade.

## Quick start

```tsx
import { SlideShow, Button } from '@geomak/ui'

<SlideShow slides={[
  { eyebrow: 'Fleet', title: 'Command your fleet', description: '…', image: hero1,
    actions: <><Button content="Start" /><Button variant="outline" content="Demo" /></> },
  { title: 'Stay compliant', image: hero2 },
]} />
```
