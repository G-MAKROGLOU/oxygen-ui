# SearchInput

A search field with a leading magnifier icon. Uses `type="search"` for the
native clear affordance and a search-friendly mobile keyboard. Full-width by
default; forwards a `ref` to the underlying `<input>`.

## Mental model

A focused utility, not a validated form field: controlled `value` + `onChange`,
a leading `icon` (override the magnifier), and the shared field foundation
(label, layout, helperText). Pair it with `AutoComplete` when you need
suggestions, or wire `onChange` to a debounced filter for a search box.

## Quick start

```tsx
import { SearchInput } from '@geomak/ui'

const [q, setQ] = useState('')

<SearchInput
  placeholder="Search vessels…"
  value={q}
  onChange={(e) => setQ(e.target.value)}
/>
```

## With a ref (focus on mount)

```tsx
const ref = useRef<HTMLInputElement>(null)
useEffect(() => ref.current?.focus(), [])

<SearchInput ref={ref} value={q} onChange={(e) => setQ(e.target.value)} />
```
