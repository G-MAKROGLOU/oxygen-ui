# Testimonials

A wall of customer quotes — testimonial, optional star rating, and author with
avatar.

## Quick start

```tsx
import { Testimonials } from '@geomak/ui'

<Testimonials title="Loved by ops teams" columns={3} testimonials={[
  { quote: 'Cut our reporting time in half.', author: 'Maria F.', role: 'Fleet Manager', avatar: url, rating: 5 },
]} />
```

Responsive grid (one column on mobile); `columns={1}` renders a single centred
featured quote. The avatar falls back to the author's initials.
