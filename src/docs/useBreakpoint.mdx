# useBreakpoint

A reactive view of the library's responsive breakpoints: for layout decisions
that live in JavaScript (which component to render, how many columns, etc.).

## Mental model

`useBreakpoint()` is built on [useMediaQuery](/docs/hooks-usemediaquery-guide--docs)
and exposes the same breakpoints as the Tailwind `screens` config. Each flag is a
**min-width** match (mobile-first): `md` is `true` at ≥ 768px. `active` is the
largest breakpoint currently met, or `'base'` below `sm`. It's SSR-safe: every
flag is `false` until mounted, then syncs.

## Quick start

```tsx
import { useBreakpoint } from '@geomak/ui'

function Nav() {
  const { md, active } = useBreakpoint()
  if (!md) return <MobileNav />          // below 768px
  return <DesktopNav dense={active === 'sm'} />
}
```

For an arbitrary one-off query (orientation, reduced-motion, print, a custom
width) reach for `useMediaQuery(query)` directly.

See the **Hooks → useBreakpoint** story (resize the viewport to watch it update).
