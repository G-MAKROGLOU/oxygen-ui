# Typography

One component for every text style in the system. A `variant` sets the visual
scale; the rendered element defaults sensibly per variant and can be overridden
with `as`.

## Mental model

Pick a `variant` for the look (display, h1–h4, subtitle, body, caption, overline,
code). The DOM element follows the variant (h1 → `<h1>`, body → `<p>`, code →
`<code>`), but visual style and semantics are decoupled: use `as` when you want
one without the other (an h1-styled card title rendered as a `<div>`). `color`,
`weight`, `align`, `truncate`, and `muted` are orthogonal modifiers.

## Quick start

```tsx
import { Typography } from '@geomak/ui'

<Typography variant="h1">Fleet overview</Typography>
<Typography variant="body" color="foreground-secondary">
  Live status for all vessels.
</Typography>
<Typography variant="overline" color="accent">Status</Typography>
<Typography variant="code">npm i @geomak/ui</Typography>
```

## Decoupling style from element

```tsx
{/* Looks like an h2, but is a <div> (no document outline impact) */}
<Typography variant="h2" as="div">Card heading</Typography>

{/* Truncated, muted secondary text */}
<Typography variant="body" truncate muted>{longPath}</Typography>
```
