## Usage

```css
/* Runtime override: affects all children */
:root {
  --color-accent:       #e63946;
  --color-accent-hover: #c1121f;
}

/* Scoped override: only within a section */
.my-section {
  --color-accent: #7209b7;
}
```

```tsx
// ThemeProvider: React tree scoped
<ThemeProvider theme={{ colors: { accent: '#e63946', 'accent-hover': '#c1121f' } }}>
  <App />
</ThemeProvider>
```
