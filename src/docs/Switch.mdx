# Switch

An on/off toggle on Radix Switch. Two labelling modes (use either or both): a
**central `label`** positioned by `layout`, and **per-state `offLabel` /
`onLabel`** flanking the track, each emphasised when its state is active.

## Mental model

Works controlled (`checked` + `onChange`) or uncontrolled (`defaultChecked`).
`onChange` reports `{ target: { checked, name } }`. Set `name` for native form
serialisation (Radix emits a hidden input).

## Quick start

```tsx
import { Switch } from '@geomak/ui'

const [on, setOn] = useState(false)

<Switch label="Email notifications" checked={on} onChange={({ target }) => setOn(target.checked)} />
```

## With the Form API

Bind with `fieldChecked`:

```tsx
<Switch label="Subscribe" {...form.fieldChecked('subscribe')} />
```

## Per-state labels & icons

```tsx
{/* "Monthly ▮ Yearly" pattern: each side highlights when active */}
<Switch offLabel="Monthly" onLabel="Yearly" checked={yearly} onChange={…} />

{/* Thumb icons for the two states */}
<Switch checkedIcon={<Check />} uncheckedIcon={<Cross />} checked={on} onChange={…} />

{/* Validation */}
<Switch label="Accept terms" required errorMessage="You must enable this" … />
```
