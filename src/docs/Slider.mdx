# Slider

A draggable track for picking a number, or a range when given two values. Tick
marks, a value tooltip, and a live readout.

## Mental model

Single mode is a `number`; range mode is a `[number, number]` tuple. The shape of
`value` (or `defaultValue`) decides the mode. `onChange` fires on every move;
`onChangeEnd` fires once when the drag/keyboard interaction settles, which is the
one to use for expensive work.

## Quick start

```tsx
import { Slider } from '@geomak/ui'

const [volume, setVolume] = useState(40)

<Slider label="Volume" showValue min={0} max={100} value={volume} onChange={setVolume} />
```

## Range mode

```tsx
const [price, setPrice] = useState<[number, number]>([20, 80])

<Slider label="Price" showValue value={price} onChange={setPrice} />
```

## With the Form API

```tsx
<Slider label="Budget" {...form.field('budget')} />
```

## Marks & formatting

```tsx
<Slider
  label="Level"
  marks={[{ value: 0, label: 'Low' }, { value: 50, label: 'Mid' }, { value: 100, label: 'High' }]}
  formatValue={(n) => `${n}%`}
  step={5}
  onChangeEnd={save}
/>
```
