# Stepper

A configurable steps indicator for multi-step flows: wizards, onboarding,
checkout, async pipelines. Horizontal or vertical, with a responsive collapse
to vertical on small screens.

## Mental model

Stepper is **controlled**: you own `current` (the active index) and, optionally,
the active step's `status`. Steps before `current` render **completed** (a check);
the step at `current` is **active**, or a spinner when `status="loading"` (for
async work), or an error mark when `status="error"`; later steps are **pending**.
Connectors fill up to the current step. Each step takes a `title`, optional
`description`, and an optional custom `icon`.

## Quick start

```tsx
import { Stepper } from '@geomak/ui'

<Stepper
  current={step}
  status={saving ? 'loading' : 'active'}
  steps={[
    { key: 'cart',    title: 'Cart', description: '3 items' },
    { key: 'address', title: 'Address' },
    { key: 'payment', title: 'Payment' },
    { key: 'done',    title: 'Confirmation' },
  ]}
/>
```

## Async advance

Flip `status` to `'loading'` while a step's work runs, then advance `current`:

```tsx
const next = async () => {
  setStatus('loading')
  await save()
  setStatus('active')
  setCurrent((c) => c + 1)
}
```
