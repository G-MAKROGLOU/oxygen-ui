# Checkbox

An accessible checkbox on Radix Checkbox: keyboard activation, `role="checkbox"`,
and a check mark that pops in with a spring. Supports a secondary `description`,
a `helperText` tooltip, left/right label placement, and the shared error
treatment.

## Mental model

Controlled with a **boolean**. `onChange` reports an event-like object:
`onChange={({ target }) => set(target.checked)}`. The label, optional
`description` (a second line, like RadioGroup options), and error all render
inside the shared field shell.

## Quick start

```tsx
import { Checkbox } from '@geomak/ui'

const [agree, setAgree] = useState(false)

<Checkbox
  htmlFor="agree"
  label="I agree to the terms"
  description="You can revoke consent any time in settings."
  checked={agree}
  onChange={({ target }) => setAgree(target.checked)}
/>
```

## With the Form API

Bind with `fieldChecked` (it reads `target.checked`):

```tsx
<Checkbox label="Accept terms" {...form.fieldChecked('accept', { required: 'You must accept' })} />
```

## Label placement & states

```tsx
<Checkbox label="Enabled" labelPosition="left" description="Box sits to the right." … />
<Checkbox label="Stacked" layout="vertical" … />          {/* box + label stacked */}
<Checkbox label="Accept" errorMessage="Required" checked={false} … />
<Checkbox label="Locked" disabled checked … />
<Checkbox label="Notify" helperText="We email about account activity." … />
```
