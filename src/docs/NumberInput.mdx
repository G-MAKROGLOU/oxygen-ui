# NumberInput

A numeric field with keyboard-driven stepper buttons, `min`/`max` clamping,
`step` increments, and floating-point-safe `precision` rounding.

## Mental model

Controlled with a **numeric** value. Unlike the text inputs, `onChange` reports
an **event-like object** carrying a number:
`onChange={(e) => set(e.target.value)}` where `e.target.value` is `number |
undefined` (empty field → `undefined`). The steppers and arrow keys respect
`min`/`max`/`step`; `precision` rounds to a fixed number of decimals to avoid
`0.1 + 0.2` drift.

## Quick start

```tsx
import { NumberInput } from '@geomak/ui'

const [qty, setQty] = useState<number | undefined>(1)

<NumberInput
  label="Quantity"
  min={0}
  max={99}
  step={1}
  value={qty}
  onChange={(e) => setQty(e.target.value)}
/>
```

## With the Form API

Bind with `fieldTarget` (it emits `{ target: { value: number } }`):

```tsx
<NumberInput label="Price" min={0} precision={2} step={0.01}
  {...form.fieldTarget('price', { required: true, min: { value: 1, message: 'Must be at least 1' } })} />
```

## Precision & clamping

```tsx
<NumberInput label="Rate" value={rate} onChange={…} step={0.01} precision={2} />  {/* 2.305 → 2.31 */}
<NumberInput label="Level" value={lvl} onChange={…} min={0} max={10} />            {/* clamps to 0–10 */}
<NumberInput label="Read-only" value={42} onChange={…} readOnly />
```
