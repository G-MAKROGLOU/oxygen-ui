# Dropdown

Single- or multi-select dropdown on Radix Popover, with an optional in-panel
search. Selected values render as removable tag chips; in multi-select the
trigger stays a fixed size and collapses overflow into a "+N more" chip.

## Mental model

Driven by an `items` array (`{ key, label, icon? }`). The value is the selected
`key` in single mode, or an **array of keys** in multi mode (`isMultiselect`).
`onChange` reports `{ target: { value, id, name } }` (form-handler shaped), so
read `e.target.value`. Pickers default to a fixed trigger width: pass
`style={{ width: '100%' }}` to fill a form column.

## Quick start

```tsx
import { Dropdown } from '@geomak/ui'

const [team, setTeam] = useState('')

<Dropdown
  label="Team"
  placeholder="Pick a team"
  items={[{ key: 'eng', label: 'Engineering' }, { key: 'design', label: 'Design' }]}
  value={team}
  onChange={(e) => setTeam(e.target.value)}
/>
```

## With the Form API

Bind with `fieldTarget`:

```tsx
<Dropdown label="Team" items={teams} style={{ width: '100%' }}
  {...form.fieldTarget('team', { required: 'Choose a team' })} />
```

## Multi-select & search

```tsx
{/* value is an array of keys; tags overflow into "+N more" */}
<Dropdown isMultiselect label="Fuels" items={fuels} value={selected} onChange={(e) => setSelected(e.target.value)} />

<Dropdown hasSearch={false} … />          {/* hide the in-panel search box */}
<Dropdown layout="horizontal" … />        {/* label beside the trigger */}
<Dropdown errorMessage="Required" required … />
```
