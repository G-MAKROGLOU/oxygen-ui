# Table

A typed data table with column renderers, client/server pagination, expandable
rows, search, and a built-in skeleton loading state.

## Mental model

`Table<T>` is generic over your row type. Describe the shape with `columns`: each
column reads a property via `keyBind` and may render a custom cell with
`component(value, row)`. Pass `rows` for the data. Pagination, expand, search, and
loading are opt-in feature blocks, so a plain table is just `columns` + `rows`.

Use a Table when comparing rows across multiple columns matters more than picking
one (otherwise prefer **List**).

## Quick start

```tsx
import { Table } from '@geomak/ui'
import type { TableColumn } from '@geomak/ui'

interface Vessel { id: string; name: string; flag: string; dwt: number }

const columns: TableColumn<Vessel>[] = [
  { key: 'name', label: 'Name', keyBind: 'name', align: 'left' },
  { key: 'flag', label: 'Flag', keyBind: 'flag' },
  { key: 'dwt',  label: 'DWT',  keyBind: 'dwt', align: 'right',
    component: (v) => v.toLocaleString() },
]

<Table columns={columns} rows={vessels} getRowKey={(r) => r.id} />
```

## Pagination, search, expand

```tsx
<Table
  columns={columns}
  rows={vessels}
  getRowKey={(r) => r.id}
  hasSearch
  pagination={{ enabled: true, perPage: 15, withPicker: true }}
  expandRow={{
    enabled: true,
    expandComponent: (row) => <VesselDetails vessel={row} />,
  }}
/>
```

## Server-side pagination + loading

```tsx
<Table
  columns={columns}
  rows={page}
  loading={isFetching}
  loadingRowCount={10}
  pagination={{
    enabled: true,
    serverSide: true,
    page,
    totalCount,
    onPageChange: setPage,
    onPerPageChange: setPerPage,
  }}
/>
```

> **Pagination position:** `PaginationOptions.position` accepts `'top'` (default), `'bottom'`, or `'both'`.
> **Expand icon:** the default chevron rotates when open; pass `expandRow.expandIcon` (rotates) or both `expandIcon` + `collapseIcon` (swap) to customise.
