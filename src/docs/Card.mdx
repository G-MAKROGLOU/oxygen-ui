# Card

A surface container with optional header, media, body, and footer sections.

## Mental model

`Card` is **compositional**. The root is a bordered surface; compose the inside
with `Card.Media` (full-bleed visual), `Card.Header` (title / subtitle / avatar /
trailing action), `Card.Body`, and `Card.Footer` (divided action row). Those
sections bring their own padding, so leave the root `padding="none"` (default)
when using them: set `padding` only for a quick flat card. `interactive` turns
the whole surface into a hover-lifting button (with `onClick`, it's
keyboard-activatable); `flush` drops the border + shadow.

## Composed

```tsx
import { Card } from '@geomak/ui'

<Card>
  <Card.Media><img src={cover} alt="" /></Card.Media>
  <Card.Header title="Aurora" subtitle="Bulk carrier" action={<Badge tone="success">At sea</Badge>} />
  <Card.Body>Off the North Sea, en route to Rotterdam.</Card.Body>
  <Card.Footer>
    <Button content="Track" size="sm" />
  </Card.Footer>
</Card>
```

## Interactive & flat

```tsx
<Card interactive onClick={open} padding="md">Whole-surface button</Card>
<Card flush padding="md">Borderless surface</Card>
```
