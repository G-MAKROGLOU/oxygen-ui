# useLocalStorage

Persist React state to `localStorage`, JSON-serialised, with a `useState`-like API.

## Mental model

`const [value, setValue, remove] = useLocalStorage(key, initialValue)`. `setValue`
takes a value or an updater, exactly like `useState`; `remove` deletes the key and
resets to `initialValue`. It's **SSR-safe** (returns `initialValue` when `window`
is absent) and stays in sync **across browser tabs** (the native `storage` event)
and **across hook instances in the same tab** (a custom event), so two components
sharing a key never drift.

## Quick start

```tsx
import { useLocalStorage } from '@geomak/ui'

const [theme, setTheme, clearTheme] = useLocalStorage('theme', 'system')

setTheme('dark')
setTheme((t) => (t === 'dark' ? 'light' : 'dark'))
clearTheme() // removes the key, resets to 'system'
```
