# CardCarousel

A horizontal, scroll-snap carousel for cards: native scrolling with optional
arrows and position dots.

## Mental model

Native CSS scroll-snap drives it: trackpad, touch, and wheel all work out of the
box. Each child becomes a snap target sized to `itemWidth`. Arrows scroll by one
slide and auto-disable at the ends; dots reflect and jump to the active slide.
The scrollbar is hidden but scrolling stays fully functional.

## Quick start

```tsx
import { CardCarousel, Card } from '@geomak/ui'

<CardCarousel itemWidth={280} showDots>
  {vessels.map((v) => (
    <Card key={v.id}>
      <Card.Header title={v.name} subtitle={v.type} />
      <Card.Body>{v.summary}</Card.Body>
    </Card>
  ))}
</CardCarousel>
```
