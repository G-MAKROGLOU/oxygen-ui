# TextArea

A multi-line text field on the shared field foundation, with optional
auto-grow, a character counter, and a configurable resize handle.

## Mental model

Controlled like `TextInput` (`value` + `onChange`, `e.target.value`). By default
it's a fixed `rows`-tall box you can resize. Turn on `autoGrow` to make it
expand with content up to `maxRows`, and `showCount` to display a
`current / maxLength` counter under the field.

## Quick start

```tsx
import { TextArea } from '@geomak/ui'

const [notes, setNotes] = useState('')

<TextArea
  label="Notes"
  rows={4}
  placeholder="Anything worth recording…"
  value={notes}
  onChange={(e) => setNotes(e.target.value)}
/>
```

## With the Form API

```tsx
<TextArea label="Bio" {...form.fieldNative('bio', { maxLength: { value: 280, message: 'Keep it under 280' } })} />
```

## Auto-grow + counter

```tsx
<TextArea label="Message" autoGrow maxRows={8} value={msg} onChange={…} />
<TextArea label="Tweet" maxLength={280} showCount value={txt} onChange={…} />
<TextArea label="Fixed" resize="none" rows={3} value={txt} onChange={…} />  {/* none | vertical | horizontal | both */}
```
