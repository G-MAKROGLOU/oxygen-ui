# Sidebar

A collapsible application sidebar: icon-only with tooltips when collapsed, icon +
label when expanded. The width animates with an ease-out-expo curve.

## Mental model

Data-driven from `sections` (each a titled group of `items`). The expand state is
**controlled** by you via `isExpanded` + `onToggle`, so the parent shell can shift
the main content by the sidebar width. Each item carries its own `icon`, `label`,
`isActive` flag, optional `badge`, and `onClick`. The component owns presentation
and animation; you own navigation and active state.

## Quick start

```tsx
import { Sidebar } from '@geomak/ui'
import { Home, Ship, Settings } from 'lucide-react'

const [open, setOpen] = useState(true)

const sections = [
  {
    key: 'main',
    title: 'Operations',
    items: [
      { key: 'home',     icon: <Home />,     label: 'Dashboard', isActive: true, onClick: goHome },
      { key: 'vessels',  icon: <Ship />,     label: 'Vessels',   badge: 3,       onClick: goVessels },
    ],
  },
  {
    key: 'system',
    items: [{ key: 'settings', icon: <Settings />, label: 'Settings', onClick: goSettings }],
  },
]

<Sidebar
  sections={sections}
  isExpanded={open}
  onToggle={() => setOpen((o) => !o)}
  footer={<ThemeSwitch checked={isDark} onChange={toggleDark} />}
/>
```

## App-shell layout

The sidebar reports its width through `expandedWidth` / `collapsedWidth`; the
parent is responsible for shifting content:

```tsx
<div style={{ marginLeft: open ? 220 : 52, transition: 'margin 240ms cubic-bezier(0.16,1,0.3,1)' }}>
  <main>…</main>
</div>
```
