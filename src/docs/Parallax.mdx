# Parallax

A scroll-driven band whose background drifts slower than the page as the frame
passes through the viewport, with centred content over an optional scrim.

## Mental model

`background` is an image URL or any node parked behind `children`. As you
scroll, the background translates by a fraction of the frame height set by
`speed` (0 = static, 1 = dramatic). Driven by Framer Motion's scroll progress,
and disabled under `prefers-reduced-motion`.

## Quick start

```tsx
import { Parallax, Button } from '@geomak/ui'

<Parallax background="/img/ocean.jpg" height={520} speed={0.35}>
  <h2 className="text-4xl font-bold text-white">Built for the open sea</h2>
  <Button content="Get started" />
</Parallax>
```
