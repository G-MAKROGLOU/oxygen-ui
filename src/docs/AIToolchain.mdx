# AI Toolchain

OxygenUI ships a built-in MCP server and Claude Code integration so AI assistants can look up component APIs, search by use-case, generate complete page components, and bootstrap entire apps, all grounded in the actual documentation you are reading now.

---

## Architecture

```
Netlify deploy
├── /                     Storybook static build (this site)
└── /mcp                  netlify/functions/mcp.ts
                           Stateless HTTP, JSON-RPC 2.0
                           Data: netlify/_data/ai-manifest.js
                           Built by: node scripts/generate-ai-manifest.mjs
```

The manifest generator scans all MDX guide files, strips Storybook boilerplate, and emits a JS module bundled into the function via esbuild. No database, no cold-start penalty.

## Context skill

The `/oxygen-ui` skill (`.claude/skills/oxygen-ui/SKILL.md`) loads the full design system context into any Claude Code session: import patterns, form binder cheat sheet, component decision matrix, provider nesting order, React Query integration patterns, useNotification usage, and a page pattern reference table. Invoke it at the start of any session where you plan to build against `@geomak/ui`.

---

## Setup

The toolchain has two parts: the **MCP server** (does the work) and the **commands + skill** (how you call it from Claude Code). A single script installs both. Choose user scope or project scope depending on your situation.

### Option A — User scope

Installs everything into `~/.claude/`. Available in every Claude Code session on your machine from that point on. Right for individuals who use `@geomak/ui` across multiple projects.

```bash
npx --package=@geomak/ui@latest setup-claude
```

Or if you already have the package installed locally:

```bash
node node_modules/@geomak/ui/scripts/setup-claude.mjs
```

This writes:

Restart Claude Code (or reload the MCP server list) after running.

---

### Option B — Project scope

Commits the toolchain into the repo so every developer gets it automatically when they clone. Right for teams.

```bash
npx --package=@geomak/ui@latest setup-claude --scope project
```

Or if you already have the package installed locally:

```bash
node node_modules/@geomak/ui/scripts/setup-claude.mjs --scope project
```

Then commit the generated files:

```bash
git add .claude/ .mcp.json
git commit -m "chore: add OxygenUI Claude Code toolchain"
```

### Local MCP server (contributors only)

```bash
npm install -g netlify-cli
yarn mcp:dev              # generates manifest + starts netlify dev on port 8888
```

The `oxygen-ui-local` entry in `.mcp.json` points to `http://localhost:8888/mcp` and is picked up automatically when you open this repository.

### Regenerating the manifest

When component docs change (new MDX files, updated props tables):

```bash
yarn generate-manifest
```

The Netlify build command runs this automatically before `storybook build`, so the deployed server is always in sync.
