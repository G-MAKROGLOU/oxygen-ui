# TimePicker

A time field with scrollable hour / minute (/ second) columns in a popover.

## Mental model

Controlled with a `string | null` time value in 24-hour `"HH:mm"` (or
`"HH:mm:ss"` with seconds). `onChange` reports the next string. `use12Hours`
shows an AM/PM UI while the value stays 24-hour.

## Quick start

```tsx
import { TimePicker } from '@geomak/ui'

const [time, setTime] = useState<string | null>('09:30')

<TimePicker label="Departure" value={time} onChange={setTime} />
```

## With the Form API

```tsx
<TimePicker label="Time" {...form.field('time', { required: true })} />
```

## Options

```tsx
<TimePicker label="Time" use12Hours value={t} onChange={setT} />          {/* AM/PM UI, 24h value */}
<TimePicker label="Time" withSeconds minuteStep={5} value={t} onChange={setT} />
```
