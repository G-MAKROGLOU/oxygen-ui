# FAB

A floating action button — a single round action, or a speed dial that expands a
labelled stack of sub-actions.

## Mental model

On its own, FAB is one round icon button anchored to a corner — pass `onClick`.
Give it `actions` and it becomes a **speed dial**: the main button toggles a
labelled, staggered stack instead of firing `onClick`. It positions `fixed` to
the viewport by default; pass `fixed={false}` to anchor inside a `relative`
container. It's icon-only, so `label` (the accessible name) is required.

## Quick start

```tsx
import { FAB } from '@geomak/ui'

<FAB icon={<PlusIcon />} label="New record" onClick={create} />
```

## Speed dial

```tsx
<FAB
  icon={<PlusIcon />}
  label="Create"
  actions={[
    { icon: <FileIcon />, label: 'Document', onClick: newDoc },
    { icon: <FolderIcon />, label: 'Folder', onClick: newFolder },
    { icon: <UploadIcon />, label: 'Upload', onClick: upload },
  ]}
/>
```
