# VirtualList

A windowed list: only the rows in view (plus a little overscan) are mounted, so
10,000 rows scroll as cheaply as 20. Zero dependencies. Set `searchable` for a
built-in filter — the canonical "virtualized search".

## Mental model

Give it `items`, a fixed `rowHeight`, and a `renderItem`. It measures its own
viewport, tracks scroll, and renders just the visible slice positioned with a
single transform. Provide a stable `getKey` for smooth reuse. Row height is
**fixed** in this lean build; for variable-height rows reach for a dedicated
virtualizer.

## Quick start

```tsx
import { VirtualList } from '@geomak/ui'

<VirtualList
  items={vessels}
  rowHeight={56}
  height={420}
  searchable
  searchKeys={['name', 'imo']}
  getKey={(v) => v.id}
  renderItem={(v) => <Row vessel={v} />}
/>
```
