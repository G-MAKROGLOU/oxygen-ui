# Checkout

A complete, two-column checkout page: the `Cart` summary on the left and the
`CreditCardForm` on the right. It composes the whole flow off the cart store —
drop it inside a `CartProvider` and it just works.

## Mental model

`Checkout` reads live items from `useCart()` (so it must be inside a
`CartProvider`) and wires the cart's quantity / remove controls back to the
store. The total is the cart subtotal plus your `summaryRows` (shipping, tax,
discounts). The pay button is **disabled whenever the cart is empty** — via the
form's `submitDisabled`, so the card fields stay editable but payment can't be
submitted with nothing to buy. It defaults its label to `Pay <total>` and stacks
to one column below the `lg` breakpoint.

## Quick start

```tsx
import { CartProvider, Checkout } from '@geomak/ui'

<CartProvider initialItems={cartItems}>
  <Checkout
    summaryRows={[
      { label: 'Shipping', value: 24 },
      { label: 'Tax (8%)', value: 178.36 },
    ]}
    onPaid={async (card) => {
      await charge(card)
    }}
  />
</CartProvider>
```
