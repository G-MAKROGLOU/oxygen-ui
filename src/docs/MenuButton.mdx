# MenuButton

A button that opens a dropdown menu of actions, built on Radix DropdownMenu none
full keyboard navigation, focus management, typeahead, and ARIA come for free.

## Mental model

Pass the rows as `items`; each has a `label`, optional `icon`, an `onSelect`
handler, and flags for `disabled`, `danger` (destructive/red), and
`separatorBefore` (a divider above the row). The trigger is a regular
[Button](/docs/buttons-button--docs): its `variant` / `size` / leading `icon`
pass straight through: with a trailing chevron that flips while the menu is open.

## Quick start

```tsx
import { MenuButton } from '@geomak/ui'

<MenuButton
  label="Actions"
  items={[
    { key: 'edit', label: 'Edit', icon: <EditIcon />, onSelect: edit },
    { key: 'dup',  label: 'Duplicate', onSelect: duplicate },
    { key: 'del',  label: 'Delete', danger: true, separatorBefore: true, onSelect: remove },
  ]}
/>
```
