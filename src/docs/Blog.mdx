# Blog

A responsive grid of article cards: cover image, tag, title, excerpt and a
byline of author / date / read-time.

## Mental model

You bring the `posts`; the component lays them out and handles hover, the tag
ribbon, and the byline. A post with an `href` renders as a link; with an
`onClick` it renders as a button; with neither, a static card. Dates are
pre-formatted strings, so you keep control of locale.

## Quick start

```tsx
import { Blog } from '@geomak/ui'

<Blog title="From the blog" columns={3} posts={[
  { title: 'Cutting CII red days', excerpt: '…', image: cover, tag: 'Compliance',
    author: 'A. Costa', date: 'May 2026', readTime: '6 min read', href: '/blog/cii' },
]} />
```
