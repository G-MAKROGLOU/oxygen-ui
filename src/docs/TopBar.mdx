# TopBar

The app-shell top navigation bar: three named slots, sticky by default, height
exposed as a CSS variable for layout children.

## Mental model

A pure layout shell with three optional slots, `brand` (leading), `center`, and
`actions` (trailing). It has no opinion about what goes in them, you compose
links, breadcrumbs, a theme switch, an avatar, whatever. It is `sticky top-0`
with `z-[100]` and publishes its height as the `--topbar-height` CSS variable so
sticky/scroll-offset children can reference it. On narrow screens the `center`
slot drops below the brand row.

## Quick start

```tsx
import { TopBar } from '@geomak/ui'

<TopBar
  brand={<Logo />}
  center={<NavLinks />}
  actions={
    <>
      <ThemeSwitch checked={isDark} onChange={toggleDark} />
      <UserAvatar />
    </>
  }
/>
```

## Consuming the height variable

```tsx
<TopBar brand={<Logo />} height={64} />

{/* a child that should stick just below the bar */}
<aside style={{ position: 'sticky', top: 'var(--topbar-height)' }}>…</aside>
```
