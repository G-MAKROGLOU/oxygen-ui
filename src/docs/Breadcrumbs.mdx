# Breadcrumbs

A navigation trail from root to the current page, with an optional collapse for
long paths.

## Mental model

Data-driven from an ordered `items` array (root → current). Each item is a
`{ label, href?, icon?, onClick? }`. The **last** item is treated as the current
page: it renders as static text with `aria-current="page"`, never a link. Set
`maxItems` to collapse the middle of a long trail into a clickable ellipsis that
expands inline. Router-agnostic: wire `href`/`onClick` to your router.

## Quick start

```tsx
import { Breadcrumbs } from '@geomak/ui'

<Breadcrumbs
  items={[
    { label: 'Home', href: '/', icon: <HomeIcon /> },
    { label: 'Fleet', href: '/fleet' },
    { label: 'Aurora' },          {/* current page */}
  ]}
/>
```

## Custom separator & collapsing

```tsx
<Breadcrumbs separator={<span>/</span>} items={trail} />

<Breadcrumbs maxItems={3} items={longTrail} />   {/* first … last-two, ellipsis expands */}
```
