# List

A vertical, clickable list with optional avatar, description, and trailing slots
per item. Rendered as a `listbox`/`option` for screen readers; activates on Enter
and Space.

## Mental model

Data-driven from `items` (each a `{ key, label, description?, avatar?, trailing? }`).
You control selection via `activeKey` and react with `onItemClick`. `density`
tunes vertical rhythm.

**When to use over a Table:** when the dataset is a simple sequence the user
browses and picks one of (nav, contact list, vessel chooser), and each row's
signal is a 1–2-line summary rather than a multi-column breakdown.

## Quick start

```tsx
import { List } from '@geomak/ui'

<List
  items={[{ key: 1, label: 'Aurora' }, { key: 2, label: 'Beacon' }]}
  activeKey={2}
  onItemClick={(it) => setSelected(it.key)}
/>
```

## With avatars + descriptions

```tsx
<List
  density="comfortable"
  items={crew.map((c) => ({
    key: c.id,
    label: c.name,
    description: c.rank,
    avatar: <Avatar src={c.photo} alt={c.name} status={c.status} />,
    trailing: <Badge count={c.unread} />,
    disabled: c.archived,
  }))}
  activeKey={selectedId}
  onItemClick={(it) => setSelectedId(it.key)}
/>
```
