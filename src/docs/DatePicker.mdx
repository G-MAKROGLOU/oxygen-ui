# DatePicker

A date field with a grid calendar popover, month/year quick-pick, and optional
`min`/`max` bounds. Dependency-free date math.

## Mental model

Controlled with a `Date | null` (`null` = no date). `onChange` reports the next
`Date` (or `null` when cleared). The trigger shows a formatted date; override
the format with `format`.

## Quick start

```tsx
import { Temporal as DatePicker } from '@geomak/ui'   // exported as `Temporal`

const [date, setDate] = useState<Date | null>(null)

<DatePicker label="Report date" value={date} onChange={setDate} />
```

## With the Form API

Bind with `field` (its `onChange` takes the value directly):

```tsx
<DatePicker label="Date" {...form.field('date', { required: 'Pick a date' })} />
```

## Bounds, format & clearing

```tsx
<DatePicker label="Date" min={new Date()} max={maxDate} value={d} onChange={setD} />
<DatePicker label="Date" format={(d) => d.toLocaleDateString('en-GB')} … />
<DatePicker label="Date" weekStartsOn={1} clearable={false} … />   {/* Monday start, no clear */}
```
