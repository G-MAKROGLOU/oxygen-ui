# Timeline

A vertical timeline of ordered events: order tracking (Order placed → Packed →
Shipped → Out for delivery → Delivered), audit trails, activity feeds: anything
sequential.

## Mental model

Each event has a `title`, optional `description`, `timestamp`, and `icon`. Drive
statuses one of two ways: set each event's `status` explicitly
(`complete | current | upcoming | error`), or pass `current` and let them
derive: events before it are `complete`, the one at it is `current` (a pulsing
node), and later ones are `upcoming` (muted). The connecting rail fills through
completed events.

## Quick start

```tsx
import { Timeline } from '@geomak/ui'

<Timeline current={2} events={[
  { key: 1, title: 'Order placed',     timestamp: 'Mon 09:24' },
  { key: 2, title: 'Gathering products', timestamp: 'Mon 11:02' },
  { key: 3, title: 'Out for shipping', timestamp: 'Tue 08:15' },
  { key: 4, title: 'Out for delivery' },
  { key: 5, title: 'Delivered' },
]} />
```

## Explicit statuses (e.g. a failure)

```tsx
<Timeline events={[
  { key: 1, title: 'Payment authorized', status: 'complete' },
  { key: 2, title: 'Payment captured',   status: 'error', description: 'Card declined.' },
  { key: 3, title: 'Fulfilment',         status: 'upcoming' },
]} />
```
