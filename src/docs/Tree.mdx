# Tree

A collapsible hierarchical tree built on Radix Accordion. Branches expand and
collapse; every node (branch or leaf) is clickable.

## Mental model

Data-driven from a nested `nodes` array (`{ key, label, children?, nodeData? }`).
A node with `children` is a branch. `onNodeClick` fires for any node with a
payload that tells you whether it was a branch (`isParent`), plus its `key`,
`label`, `parentLabel`, and any attached `data`. Control the initial open state
with `defaultExpandAll` or `defaultExpandedKeys`.

This is a **display/navigation** tree — for picking a single value inside a form,
use **TreeSelect** instead.

## Quick start

```tsx
import { Tree } from '@geomak/ui'

<Tree
  nodes={[
    { key: 'eu', label: 'Europe', children: [
      { key: 'no',  label: 'North Sea' },
      { key: 'med', label: 'Mediterranean' },
    ]},
    { key: 'as', label: 'Asia', children: [{ key: 'sg', label: 'Singapore Strait' }] },
  ]}
  defaultExpandedKeys={['eu']}
  onNodeClick={(p) => {
    if (!p.isParent) selectRegion(p.key)
  }}
/>
```
