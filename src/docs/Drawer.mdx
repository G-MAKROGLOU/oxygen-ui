# Drawer

A side-sliding panel powered by Radix Dialog + Framer Motion. Same controlled
model as Modal, but it enters from the left or right edge.

## Mental model

Controlled via `open` + `onClose`. `placement` picks the edge it slides from and
`width` sets the panel width. Like Modal, it has an optional built-in OK/Cancel
footer (`hasFooter`, `onOk`, `onCancel`), or supply your own actions in `children`.

Reach for a Drawer over a Modal when the content is a side task that benefits from
context staying visible behind it (filters, detail inspector, quick edit).

## Quick start

```tsx
import { Drawer } from '@geomak/ui'

const [open, setOpen] = useState(false)

<Drawer
  open={open}
  placement="right"
  width={420}
  onClose={() => setOpen(false)}
  title="Filters"
>
  <FilterForm />
</Drawer>
```
