# FadingBase

A fade-in / fade-out container. Mounts when `isMounted` becomes true and unmounts
after a 300ms fade-out when it goes false.

## Mental model

Drive it with a boolean `isMounted`. On true it renders and fades in on the next
frame; on false it fades out, then unmounts after the transition completes (so the
exit animation actually plays). A pure CSS opacity transition, no
`react-transition-group`, no theme-context dependency.

## Quick start

```tsx
import { FadingBase } from '@geomak/ui'

<FadingBase isMounted={isPageVisible}>
  <PageContent />
</FadingBase>
```

## Route transition

```tsx
const [show, setShow] = useState(false)
useEffect(() => { setShow(true); return () => setShow(false) }, [route])

<FadingBase isMounted={show}>
  <RouteView />
</FadingBase>
```
