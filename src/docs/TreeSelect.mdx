# TreeSelect

A hierarchical single-select on Radix Popover: pick one node from a nested tree,
with full keyboard navigation (arrows expand/collapse + move, Enter selects).

## Mental model

Driven by a nested `items` array (`{ key, label, icon?, disabled?, children? }`).
A node with `children` is a branch; leaves are selectable. The value is the
selected `key`. `onChange` reports `{ target: { value, id, name } }` (form-handler
shaped). `parentsSelectable` controls whether branches can be picked or only
expand/collapse.

## Quick start

```tsx
import { TreeSelect } from '@geomak/ui'

const [region, setRegion] = useState(null)

<TreeSelect
  label="Region"
  items={[
    { key: 'eu', label: 'Europe', children: [
      { key: 'no', label: 'North Sea' },
      { key: 'med', label: 'Mediterranean' },
    ]},
    { key: 'as', label: 'Asia', children: [{ key: 'sg', label: 'Singapore Strait' }] },
  ]}
  value={region}
  onChange={(e) => setRegion(e.target.value)}
/>
```

## With the Form API

Bind with `fieldTarget`:

```tsx
<TreeSelect label="Region" items={tree} {...form.fieldTarget('region', { required: true })} />
```

## Options

```tsx
<TreeSelect parentsSelectable={false} … />       {/* branches only expand, leaves select */}
<TreeSelect defaultExpandedKeys={['eu']} … />    {/* open these branches initially */}
<TreeSelect layout="horizontal" required errorMessage="Required" … />
```
