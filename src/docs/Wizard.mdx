# Wizard

A guided product tour. It spotlights real elements on the page one at a time and
floats a tooltip beside each, with Next / Back / Done controls.

## Mental model

Wrap the subtree you want to tour in `<Wizard>` and pass an ordered `steps` array.
Each step points at a live element via a `stepRef` (a React ref into that subtree)
and supplies the tooltip `description`, optional `title`, and `placement`. The
component highlights `steps[i].stepRef`, dims the rest, and advances on Next.

Completion is remembered in `localStorage` under `storageKey` so the tour won't
reopen — pass `storageKey={null}` to always run it (tests, replayable tours).

## Quick start

```tsx
import { Wizard } from '@geomak/ui'

const headerRef  = useRef<HTMLElement>(null)
const sidebarRef = useRef<HTMLElement>(null)
const dashRef    = useRef<HTMLElement>(null)

<Wizard
  steps={[
    { stepRef: headerRef,  title: 'Welcome',    description: 'This is the app header.',          placement: 'bottom' },
    { stepRef: sidebarRef, title: 'Navigation', description: 'Jump between sections here.',      placement: 'right'  },
    { stepRef: dashRef,    title: 'Workspace',  description: 'Your dashboard lives here.',       placement: 'left'   },
  ]}
  onComplete={() => markOnboarded()}
>
  <AppShell headerRef={headerRef} sidebarRef={sidebarRef} dashRef={dashRef} />
</Wizard>
```

## Always-run / non-dismissible tours

```tsx
<Wizard steps={steps} storageKey={null} dismissible={false}>
  <Flow />
</Wizard>
```
