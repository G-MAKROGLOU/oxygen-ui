# Video

A responsive video frame that keeps its aspect ratio at any width.

## Mental model

Give it a file `src` for a native `<video>` (with an optional click-to-play
poster overlay) or an `embedUrl` for an `<iframe>` (YouTube, Vimeo, …). The
frame holds its `aspect` ratio fluidly, so it scales cleanly in any column.

## Quick start

```tsx
import { Video } from '@geomak/ui'

<Video src="/clips/tour.mp4" poster="/clips/tour.jpg" title="Product tour" />
<Video embedUrl="https://www.youtube.com/embed/abc123" title="Webinar" aspect="16/9" />
```
