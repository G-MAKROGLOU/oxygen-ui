# PdfViewer

A virtualized, in-browser PDF viewer built on [pdfjs-dist](https://mozilla.github.io/pdf.js/). It renders only the pages currently inside the viewport, supports a selectable text layer with in-document search, and provides a configurable toolbar with zoom, page-jump, fit controls, download, and print.

**pdfjs-dist is loaded lazily.** It is not part of the entry bundle and only fetches on first render.

```tsx
import { PdfViewer } from '@geomak/ui'
```

---

## Source types

`PdfViewer` accepts four source shapes via the `source` prop.

| Shape | When to use |
|---|---|
| `string` or `URL` | Remote URL; the only mode that performs a network request. |
| `File` or `Blob` | Local file from an `<input type="file">` or a `fetch` response blob. |
| `ArrayBuffer` or `Uint8Array` | Programmatic bytes, e.g. generated by jsPDF or received from a WebSocket. No network. |

```tsx
// Remote URL
<PdfViewer source="https://example.com/report.pdf" />

// File from <input type="file">
<PdfViewer source={fileInputRef.current.files[0]} />

// Programmatic bytes
<PdfViewer source={uint8ArrayBytes} />
```

For remote sources, pass HTTP headers or credentials via the `remote` prop:

```tsx
<PdfViewer
  source="https://api.example.com/report.pdf"
  remote={{ httpHeaders: { Authorization: `Bearer ${token}` } }}
/>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `source` | `string \| URL \| File \| Blob \| ArrayBuffer \| Uint8Array` | required | The document source. |
| `toolbar` | `boolean \| ToolbarConfig` | `true` | Show or configure the toolbar. |
| `textLayer` | `boolean` | `true` | Render selectable text spans over each page. Required for search. |
| `thumbnails` | `boolean` | `false` | Show a collapsible thumbnail rail on the left. |
| `initialPage` | `number` | `1` | 1-based page number to scroll to on first load. |
| `zoom` | `number` | fit-width | Initial scale factor (1 = 100%). |
| `height` | `number \| string` | `'100%'` | Container height. |
| `width` | `number \| string` | `'100%'` | Container width. |
| `workerSrc` | `string` | CDN URL | Custom pdfjs worker URL (see Worker configuration). |
| `remote` | `object` | none | Options passed to pdfjs for remote sources (headers, credentials, range requests). |
| `overscan` | `number` | `2` | Pages to render above and below the viewport. |
| `onLoad` | `(pageCount: number) => void` | none | Called after the document loads. |
| `onError` | `(error: Error) => void` | none | Called when loading fails. |

---

## Toolbar

The `toolbar` prop is either `false` (hide entirely) or an object where each key toggles a control. All keys default to `true`.

| Key | Control |
|---|---|
| `pager` | Page-jump input and prev/next arrows |
| `zoom` | Zoom percentage display, +/- buttons, fit-width and fit-page toggles |
| `search` | Debounced in-document search (highlights all matches) |
| `download` | Download the source file |
| `print` | Print |

```tsx
// Show only navigation
<PdfViewer source={bytes} toolbar={{ pager: true }} />

// No toolbar
<PdfViewer source={bytes} toolbar={false} />
```

---

## Text layer and search

When `textLayer` is `true`, invisible `<span>` elements are overlaid on each page, aligned to PDF glyphs via transform matrices from pdfjs-dist. Text is selectable and copy-pasteable.

The search bar requires `textLayer`. Search is debounced (220 ms) and highlights all matches on every rendered page simultaneously.

---

## Virtualization

Only pages whose bounding box overlaps the visible viewport are rendered to canvas. Off-screen pages are represented by empty placeholder `<div>` elements that match the page's pixel height, keeping the scrollbar accurate.

The `overscan` prop (default `2`) controls how many extra pages are rendered above and below the viewport. Increase it to reduce blank flash on fast scrolls; decrease it to reduce memory use.

---

## Worker configuration

pdfjs-dist uses a Web Worker for off-thread decoding. By default the viewer injects a version-pinned CDN URL. For air-gapped environments or strict CSPs, bundle the worker and point to it:

```tsx
import workerUrl from 'pdfjs-dist/build/pdf.worker.min.mjs?url' // Vite

<PdfViewer source={bytes} workerSrc={workerUrl} />
```

## Recipes

### File from a picker

```tsx
const [file, setFile] = useState<File | null>(null)

<input type="file" accept=".pdf" onChange={e => setFile(e.target.files?.[0] ?? null)} />
{file && <PdfViewer source={file} />}
```

### Authenticated API fetch

```tsx
const [bytes, setBytes] = useState<Uint8Array | null>(null)

useEffect(() => {
  fetch('/api/report.pdf', { headers: { Authorization: `Bearer ${token}` } })
    .then(r => r.arrayBuffer())
    .then(buf => setBytes(new Uint8Array(buf)))
}, [])

{bytes && <PdfViewer source={bytes} />}
```

### Embed without chrome

```tsx
<PdfViewer source={bytes} toolbar={false} textLayer={false} height={480} width={340} />
```

### Start on a specific page at a specific zoom

```tsx
<PdfViewer source={bytes} initialPage={5} zoom={1.5} />
```

---

## Caveats

- **SSR:** pdfjs-dist is imported inside a `useEffect`, so server-side rendering is safe. Hydration renders a skeleton.
- **CSP:** The default CDN worker URL requires `cdnjs.cloudflare.com` in your `worker-src` directive. Supply a bundled worker via `workerSrc` to avoid this.
- **Large PDFs:** For documents with hundreds of pages, set `textLayer={false}` until the user requests search. The text layer multiplies DOM node count significantly.
