# Spreadsheet

A virtualized, multi-sheet spreadsheet component. Accepts in-memory data or user-opened files, supports inline editing with type coercion, sortable columns, context menus, and Export/Open via a File menu. xlsx and PDF export are lazy-loaded, so the initial bundle impact is near-zero.

```tsx
import { Spreadsheet } from '@geomak/ui'
```

---

## Data model

### SheetData

Each `SheetData` object maps to a worksheet tab.

```ts
interface SheetData {
  name: string
  columns: GridColumn[]
  rows: Record<string, CellValue>[]
}

type CellValue = string | number | boolean | null | undefined | Date
```

### GridColumn

```ts
interface GridColumn {
  key: string
  label: string
  width?: number
  align?: 'left' | 'center' | 'right'
  editable?: boolean
  type?: 'text' | 'number' | 'date' | 'boolean'
}
```

| Field | Default | Description |
|---|---|---|
| `key` | required | The row-object key this column reads from. |
| `label` | required | Display text in the header row. |
| `width` | `120` | Column width in pixels. User-resizable. |
| `align` | `'left'` | Cell text alignment. |
| `editable` | inherits `Spreadsheet.editable` | Per-column editability override. |
| `type` | `'text'` | Controls input type during editing and sort comparison. |

---

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `data` | `SheetData[]` | none | In-memory data. No network, no file I/O. |
| `file` | `File` \| `null` | none | A `.xlsx` or `.csv` file to parse and display. `data` takes precedence when both are provided. |
| `editable` | `boolean` | `false` | Enable inline cell editing. |
| `sortable` | `boolean` | `false` | Enable column sorting. |
| `virtualize` | `boolean` | `true` | Virtualize rendering for large datasets (auto-enabled above 500 rows). |
| `height` | `number` \| `string` | `'100%'` | Container height. |
| `width` | `number` \| `string` | `'100%'` | Container width. |
| `emptyRows` | `number` | `0` | Append blank rows for spreadsheet-like feel. Display-only. |
| `emptyCols` | `number` | `0` | Append blank columns. Display-only. |
| `contextMenus` | `boolean` | `false` | Right-click row context menu (insert/delete rows). |
| `rowHeight` | `number` | `32` | Row height in pixels. Uniform; required for virtual scroll. |
| `onCellEdit` | `(edit: CellEdit, updated: SheetData[]) => void` | none | Called on every cell change. |
| `onChange` | `(data: SheetData[]) => void` | none | Called with the full updated data after any edit. |
| `onSheetsChange` | `(sheets: SheetData[]) => void` | none | Enables sheet add/rename/delete UI when provided. |

---

## Source types

| Prop | Description |
|---|---|
| `data: SheetData[]` | In-memory data. Recommended for programmatic use. |
| `file: File` | A `.xlsx` or `.csv` file. Parsed lazily on first render using the bundled xlsx library. |

---

## Editing

Enable editing with `editable`. Each cell change fires `onCellEdit`:

```ts
interface CellEdit {
  sheetIndex: number
  rowIndex: number
  columnKey: string
  value: CellValue
  previousValue: CellValue
}
```

Controlled pattern:

```tsx
const [data, setData] = useState(initialData)

<Spreadsheet
  data={data}
  editable
  onCellEdit={(edit, updated) => setData(updated)}
/>
```

### Value coercion

When a column has a `type` set, the raw input string is coerced before the edit event fires:

| Column type | Coercion |
|---|---|
| `'number'` | `parseFloat`; invalid strings become `null` |
| `'boolean'` | `'true'`, `'1'`, `'yes'` become `true`; everything else becomes `false` |
| `'date'` | `new Date(value)`; invalid strings become `null` |
| `'text'` | No coercion |

---

## Sorting

`sortable` enables column sorting. Click a header to toggle ascending/descending/off. Sort does not mutate the `data` prop; the original order is restored when sorting is cleared.

Numeric columns sort numerically, date columns sort chronologically, and all other types sort lexicographically.

---

## Sheet management

When `onSheetsChange` is provided, the tab bar shows an Add button and each tab gets a right-click context menu with rename and delete options:

```tsx
<Spreadsheet
  data={sheets}
  onSheetsChange={setSheets}
/>
```

---

## File menu

The toolbar File menu provides:

| Action | Formats | Notes |
|---|---|---|
| Open | `.xlsx`, `.csv` | Parses the file with xlsx and replaces current data |
| Export | `.xlsx`, `.csv`, `.pdf` | Builds the file lazily from current in-memory data |

All exports use the same lazy-loaded xlsx and jsPDF modules that `useExcel` and `usePdf` use. The first export fetches the chunk; subsequent exports are instant.

PDF export renders each sheet to an off-screen canvas: one page per sheet.

---

## Virtualization

When `virtualize` is `true`, only rows inside the visible viewport are rendered. Row heights are uniform (`rowHeight` prop, default `32`), so the virtual scroller can compute offsets without measuring. Auto-enabled above 500 rows.

Set `virtualize={false}` to render all rows (useful for printing or accessibility tools).

## Recipes

### Read-only display with export

```tsx
<Spreadsheet data={sheets} />
```

### Editable controlled

```tsx
const [data, setData] = useState(initialSheets)

<Spreadsheet data={data} editable onCellEdit={(_, updated) => setData(updated)} />
```

### File picker

```tsx
const [file, setFile] = useState<File | null>(null)

<input type="file" accept=".xlsx,.csv" onChange={e => setFile(e.target.files?.[0] ?? null)} />
{file && <Spreadsheet file={file} />}
```

### Fixed size inside a panel

```tsx
<Spreadsheet data={sheets} height={480} width="100%" />
```

---

## Caveats

- **PDF export and large sheets:** PDF export captures only the virtualized visible rows. Export as `.xlsx` if you need all rows in a portable format.
- **CSV multi-sheet:** CSV is single-sheet. Exporting a multi-sheet workbook to CSV exports only the active sheet.
- **Column resize:** User column width changes are local state and are not reflected back through any prop.
