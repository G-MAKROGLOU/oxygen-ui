# Spreadsheet

A virtualized, multi-sheet spreadsheet component. Accepts in-memory data or user-opened files, supports inline editing with type coercion, sortable columns, context menus, and Export/Open via a File menu. xlsx and PDF export are lazy-loaded, so the initial bundle impact is near-zero.

```tsx
import { Spreadsheet } from '@geomak/ui'
```

---

## Data model

### SheetData

Each `SheetData` object maps to a worksheet tab.

```ts
interface SheetData {
  name: string
  columns: GridColumn[]
  rows: Record<string, CellValue>[]
}

type CellValue = string | number | boolean | null | undefined | Date
```

### GridColumn

```ts
interface GridColumn {
  key: string
  label: string
  width?: number
  align?: 'left' | 'center' | 'right'
  editable?: boolean
  type?: 'text' | 'number' | 'date' | 'boolean'
}
```

## Editing

Enable editing with `editable`. Each cell change fires `onCellEdit`:

```ts
interface CellEdit {
  sheetIndex: number
  rowIndex: number
  columnKey: string
  value: CellValue
  previousValue: CellValue
}
```

Controlled pattern:

```tsx
const [data, setData] = useState(initialData)

<Spreadsheet
  source={data}
  editable
  onCellEdit={(edit) => console.log(edit)}
  onChange={(next) => setData(next)}
/>
```

## Sorting

`sortable` enables column sorting. Click a header to toggle ascending/descending/off. Sort does not mutate the `source` prop; the original order is restored when sorting is cleared.

Numeric columns sort numerically, date columns sort chronologically, and all other types sort lexicographically.

---

## Sheet management

When `editable` is true and `allowAddSheet` is not explicitly disabled, a **+** button appears next to the sheet tabs. Click the **x** on a tab to delete it (the last sheet cannot be deleted). Right-click a tab for rename and delete options.

All exports use the same lazy-loaded xlsx and jsPDF modules that `useExcel` and `usePdf` use. The first export fetches the chunk; subsequent exports are instant.

PDF export renders each sheet to an off-screen canvas: one page per sheet.

---

## Virtualization

When `virtualize` is `true`, only rows inside the visible viewport are rendered. Row heights are uniform (`rowHeight` prop, default `32`), so the virtual scroller can compute offsets without measuring. Auto-enabled above 500 rows.

Set `virtualize={false}` to render all rows (useful for printing or accessibility tools).

## Recipes

### Read-only display with export

```tsx
<Spreadsheet source={sheets} />
```

### Editable controlled

```tsx
const [data, setData] = useState(initialSheets)

<Spreadsheet source={data} editable onChange={(next) => setData(next)} />
```

### File picker

```tsx
const [file, setFile] = useState<File | null>(null)

<input type="file" accept=".xlsx,.csv" onChange={e => setFile(e.target.files?.[0] ?? null)} />
{file && <Spreadsheet source={file} />}
```

### Fixed size inside a panel

```tsx
<Spreadsheet source={sheets} height={480} width="100%" />
```

---

## Caveats

- **PDF export and large sheets:** PDF export captures only the virtualized visible rows. Export as `.xlsx` if you need all rows in a portable format.
- **CSV multi-sheet:** CSV is single-sheet. Exporting a multi-sheet workbook to CSV exports only the active sheet.
- **Column resize:** User column width changes are local state and are not reflected back through any prop.
