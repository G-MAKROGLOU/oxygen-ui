# usePdf

A hook that wraps [jsPDF](https://github.com/parallax/jsPDF) to export one or more `HTMLCanvasElement` objects as a multi-page PDF. The library already bundles jsPDF; `usePdf` adds orientation handling, aspect-ratio-preserving scaling, title headers, and browser-download wiring.

**jsPDF is lazy-loaded.** The import happens on the first `exportCanvases` call and is not included in the initial bundle.

```tsx
import { usePdf } from '@geomak/ui'

const { exportCanvases, isExporting } = usePdf()
```

---

## Return type

```ts
interface UsePdfReturn {
  exportCanvases(pages: PdfPage[], options?: PdfExportOptions): Promise<void>
  isExporting: boolean
}
```

---

## Types

### PdfPage

```ts
interface PdfPage {
  canvas: HTMLCanvasElement
  title?: string
}
```

| Field | Description |
|---|---|
| `canvas` | The source canvas. Canvases with `width === 0` or `height === 0` are silently skipped. |
| `title` | Optional page heading. Rendered bold and centered, reserving 28 px at the top of the page. |

### PdfExportOptions

```ts
interface PdfExportOptions {
  fileName?: string
  orientation?: 'landscape' | 'portrait'
  onSave?: (blob: Blob, name: string) => void | Promise<void>
}
```

| Field | Default | Description |
|---|---|---|
| `fileName` | `'export'` | File name without extension. `.pdf` is appended automatically. |
| `orientation` | `'landscape'` | Page orientation. |
| `onSave` | none | When provided, receives the Blob instead of triggering a download. |

---

## exportCanvases

Converts an array of canvases into a PDF document and either triggers a browser download or calls `onSave`.

**Per page:**

1. `canvas.toDataURL('image/png')` captures the current pixel content.
2. If `title` is set, 28 px is reserved at the top for a bold centered heading.
3. The canvas image is scaled to fill the remaining page area, preserving the canvas aspect ratio (letterboxed, never stretched or cropped).
4. The image is added to the jsPDF document.

Canvases with zero dimensions are skipped without error.

```tsx
const { exportCanvases, isExporting } = usePdf()

// Off-screen canvas (no DOM attachment needed)
const canvas = document.createElement('canvas')
canvas.width = 800
canvas.height = 500
// ... draw your chart ...

await exportCanvases(
  [{ canvas, title: 'Fleet CO2 Emissions 2024' }],
  { fileName: 'emissions', orientation: 'landscape' }
)
```

### Multiple pages

```tsx
await exportCanvases(
  [
    { canvas: emissionsCanvas, title: 'CO2 Emissions' },
    { canvas: fuelCanvas,      title: 'Fuel Consumption' },
    { canvas: distanceCanvas,  title: 'Distance Sailed' },
  ],
  { fileName: 'fleet-report' }
)
```

### Canvas from a charting library

```tsx
const canvasRef = useRef<HTMLCanvasElement>(null)

// After the chart has rendered:
await exportCanvases([{ canvas: canvasRef.current!, title: 'Revenue' }])
```

`canvas.toDataURL()` is called at export time, so it captures whatever the canvas holds at that moment.

### Upload instead of download

```tsx
await exportCanvases([{ canvas }], {
  onSave: async (blob, name) => {
    const form = new FormData()
    form.append('file', blob, name)
    await fetch('/api/reports', { method: 'POST', body: form })
  },
})
```

## isExporting

```tsx
<Button disabled={isExporting} onClick={() => exportCanvases(pages)}>
  {isExporting ? 'Generating...' : 'Export PDF'}
</Button>
```

## Caveats

- **Draw before export.** `canvas.toDataURL()` returns a blank image if no pixels have been painted. Ensure the chart has finished rendering before calling `exportCanvases`.
- **CORS for external images.** If the canvas draws images from cross-origin URLs, the canvas becomes tainted and `toDataURL()` throws. Use a CORS-enabled image server or proxy.
- **Image-based output.** The PDF is purely raster. Text inside a canvas is not selectable. For text-searchable PDFs, use `PdfViewer` with a server-generated PDF that includes a text layer.
