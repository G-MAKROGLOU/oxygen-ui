# useExcel

A hook that wraps [SheetJS (xlsx)](https://sheetjs.com/) to provide ergonomic Excel export and parse operations. The library already bundles xlsx; `useExcel` adds type safety, worksheet name sanitization, and browser-download wiring.

**xlsx is lazy-loaded.** The import happens on the first call to `exportSheets` or `readWorkbook` and is not included in the initial bundle.

```tsx
import { useExcel } from '@geomak/ui'

const { exportSheets, readWorkbook, isExporting } = useExcel()
```

---

## Return type

```ts
interface UseExcelReturn {
  exportSheets(sheets: ExcelSheetInput[], options?: ExportSaveOptions): Promise<void>
  readWorkbook(source: File | Blob | ArrayBuffer | Uint8Array): Promise<ParsedSheet[]>
  isExporting: boolean
}
```

---

## Types

### ExcelSheetInput

```ts
interface ExcelSheetInput {
  name: string
  columns?: string[]
  rows: Record<string, CellValue>[] | CellValue[][]
}

type CellValue = string | number | boolean | null | undefined | Date
```

| Field | Description |
|---|---|
| `name` | Worksheet name. Sanitized automatically (max 31 chars, restricted chars replaced with `_`). |
| `columns` | Optional explicit column order used as the bold header row. Inferred from row-object keys when omitted. |
| `rows` | Array of key-value objects or positional `CellValue` arrays. Both shapes are supported and can be mixed across sheets. |

### ExportSaveOptions

```ts
interface ExportSaveOptions {
  fileName?: string
  onSave?: (blob: Blob, name: string) => void | Promise<void>
}
```

| Field | Default | Description |
|---|---|---|
| `fileName` | `'export'` | File name without extension. `.xlsx` is appended automatically. |
| `onSave` | none | When provided, receives the Blob instead of triggering a download. |

### ParsedSheet

```ts
interface ParsedSheet {
  name: string
  rows: Record<string, CellValue>[]
}
```

## exportSheets

Builds a `.xlsx` workbook and either triggers a browser download or calls `onSave`.

Per worksheet:

1. Header row is written bold, from `columns` or derived from the union of all row-object keys.
2. Object rows are mapped by key order; array rows are written positionally.
3. Column widths are auto-sized from the longest cell value, capped at 40 characters.
4. Worksheet names longer than 31 characters are truncated; the characters `\ / ? * [ ] :` are replaced with `_`.

```tsx
const { exportSheets, isExporting } = useExcel()

// Object rows with explicit column order
await exportSheets(
  [
    {
      name: 'Fleet',
      columns: ['Vessel', 'IMO', 'DWT (t)', 'CII'],
      rows: [
        { Vessel: 'MV Aurora', IMO: 9876543, 'DWT (t)': 81200, CII: 'B' },
        { Vessel: 'MV Borealis', IMO: 9123456, 'DWT (t)': 115000, CII: 'C' },
      ],
    },
  ],
  { fileName: 'fleet' }
)

// Positional array rows
await exportSheets(
  [
    {
      name: 'Cargo',
      columns: ['Port', 'Cargo (t)', 'ETD'],
      rows: [
        ['Rotterdam', 42000, '2024-03-12'],
        ['Singapore', 38500, '2024-03-28'],
      ],
    },
  ],
  { fileName: 'cargo' }
)
```

### Upload instead of download

```tsx
await exportSheets([sheet], {
  onSave: async (blob, name) => {
    await fetch('/api/upload', { method: 'POST', body: blob })
  },
})
```

## readWorkbook

Parses any Excel workbook. Returns one `ParsedSheet` per worksheet. The first row of each worksheet becomes the header keys; all subsequent rows become `Record<header, CellValue>`.

```tsx
const { readWorkbook } = useExcel()

// From a file picker
const [parsed] = await readWorkbook(event.target.files[0])
console.log(parsed.name)  // worksheet name
console.log(parsed.rows)  // [{ Vessel: 'MV Aurora', ... }]

// From a fetch response
const buf = await fetch('/api/data.xlsx').then(r => r.arrayBuffer())
const sheets = await readWorkbook(buf)
```

Empty worksheets return `rows: []`. They are not skipped.

---

## isExporting

`isExporting` is `true` while `exportSheets` is running. Use it to disable buttons and show loading indicators:

```tsx
<Button disabled={isExporting} onClick={() => exportSheets([sheet])}>
  {isExporting ? 'Building...' : 'Download .xlsx'}
</Button>
```

`readWorkbook` does not set `isExporting`.
