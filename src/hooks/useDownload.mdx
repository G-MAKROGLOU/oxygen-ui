# useDownload

A stateless hook that owns the single implementation of the **blob to object-URL to anchor to click to deferred revoke** pattern. Both `useExcel` and `usePdf` delegate their browser-download step here.

```tsx
import { useDownload } from '@geomak/ui'

const { saveBlob, saveFromBase64 } = useDownload()
```

---

## Return type

```ts
interface UseDownloadReturn {
  saveBlob(blob: Blob, fileName: string): void
  saveFromBase64(base64: string, fileName: string, mimeType?: string): void
}
```

Both functions have stable identities (`useCallback` with stable deps). They are safe to pass as event-handler props without causing re-renders.

---

## saveBlob

```ts
saveBlob(blob: Blob, fileName: string): void
```

Triggers a browser download for any `Blob`.

**Steps:**

1. `URL.createObjectURL(blob)` allocates a one-time URL.
2. A transient `<a download="fileName">` anchor is created (never appended to the DOM).
3. `.click()` initiates the download.
4. `setTimeout(() => URL.revokeObjectURL(url), 0)` revokes after one event-loop tick so the click registers before the URL is released.

**SSR safety:** the function checks `typeof window === 'undefined'` and returns early on the server.

```tsx
const { saveBlob } = useDownload()

const downloadCsv = () => {
  const csv = 'vessel,imo\nMV Aurora,9876543\n'
  saveBlob(new Blob([csv], { type: 'text/csv;charset=utf-8' }), 'fleet.csv')
}
```

## saveFromBase64

```ts
saveFromBase64(base64: string, fileName: string, mimeType?: string): void
```

Decodes a base64 string and downloads the result. Handles two input shapes:

| Input shape | MIME resolution |
|---|---|
| `data:<mime>;base64,<payload>` (data URI) | Extracted from the prefix automatically |
| `<payload>` (raw base64, no prefix) | Supplied via the `mimeType` argument |

Falls back to `'application/octet-stream'` when both the prefix and the argument are absent.

```tsx
const { saveFromBase64 } = useDownload()

// Data URI: MIME inferred from the prefix
saveFromBase64(dataUri, 'image.png')

// Raw base64: MIME supplied explicitly
saveFromBase64(rawBase64, 'report.pdf', 'application/pdf')
```

**Steps:** strip data-URI prefix, `atob(payload)`, copy into `Uint8Array`, construct `Blob`, delegate to `saveBlob`.

---

## Integration with useExcel and usePdf

You do not need `useDownload` directly if you are using the higher-level hooks. Both `useExcel.exportSheets` and `usePdf.exportCanvases` call `saveBlob` internally when no `onSave` callback is passed.

Use `useDownload` directly when you have a raw `Blob` from a `fetch` response, a WebSocket frame, or any other source outside of Excel or PDF generation.
